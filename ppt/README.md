# 数蚕智能 · 产品定位与未来发展方向 专题研讨会

Guizang PPT Skill · Swiss Style · IKB（默认开启「投屏模式」：浅底深字）

## 打开

```bash
cd ppt && python3 -m http.server 8765
# http://127.0.0.1:8765/
```

## 编辑 / 保存

顶部工具条：
- **编辑**：开启后可直接点选文字修改
- **保存**：写入浏览器 localStorage（Ctrl/Cmd+S）
- **下载 HTML**：导出含当前修改的完整文件
- **重置**：恢复原始内容
- **投屏模式**：浅底深字（默认开）

## 操作

`←` `→` / 滚轮翻页 · `Esc` 索引 · `B` 低功耗

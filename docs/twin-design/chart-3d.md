# 数字孪生大屏 · 3D 图表选型与实现（twin-charts.js + G2 v5）

## 1. 先回答"哪些数据可以做成柱状图 / 环形图"

判据只有三条，写在 `twin-charts.js` 与 `twin-scene-v2.js` 的注释里，不许下轮随手换图型把语义换掉：

1. **各类相加等于总数** → 才允许环形（构成占比）。子集（逾期/临期是「未完成」的子集）塞进同一个环就是重复计数。
2. **同类别之间只比量级、不必相加** → 柱状。88 vs 3 用环形会把小片压成看不见，那是骗人。
3. **时序趋势** → 折线带。

## 2. 为什么是「等轴挤出」而不是透视 3D

大屏的读数要能直接比大小。透视 3D 里近处的柱子天然比远处高（同一数值两种高度），
在售前投影和运维读屏两个场景里都是错的。所以：**数据面保持正交**（y 仍是线性可比刻度、
扇区角度严格按数值算），只挤出顶面与侧面的厚度。立体感来自几何，不来自欺骗。

深度用数据单位表达但相对值固定（`dy = yMax × 5.5%`），于是像素深度恒等于绘图高度的 5.5%——
换数据范围不会变胖变瘦，也不需要知道绘图区的像素尺寸。

## 3. G2 v5 实现要点与真实踩坑

| 坑 | 现象 | 结论 |
|---|---|---|
| `style.radius: [3,3,0,0]` | interval **整条不渲染**，无报错 | v5 的 radius 数组在这里不生效；要圆角面请用 polygon 自己画 |
| 把 hex 存进数据再 `encode.color` | 蓝红两组被序数色板重染成紫绿，图例一堆无语义色块 | 面颜色走 `style: { fill: d => d.c }` 回调，**不建 color 比例尺** |
| `view.children` 里 interval 用数组 encode | `t.getBandWidth is not a function` | 立体几何全部用 `polygon`（每面一组点），正面交给 polygon 的 front 面 |
| 环形百分比贴在扇区中角外侧 | 左右两侧标签被画布裁掉 | 窄面（≤200px）不用环形；宽面把图例排成环下方一行 |
| 双序列端点标签 | 两条线最后一点常在同一高度，叠成「温度46.9%RH」 | 最小间距要**按像素换算**（62px 高、y 域 1.18 → 需 .28 单位），原来写 .1 等于没让 |
| 图表容器挂在 `renderTables()` 里 | 心跳重建 innerHTML 把 canvas 连锅端走，而签名没变又不重绘 → 8 张图只剩 2 张 | **心跳不许重建有状态的子树**（同 FR-30b）。表格改成骨架只建一次、每拍只改数字；图表容器一律是稳定兄弟节点 |
| 每次数据变化 `destroy()` + `new Chart()` | `state.rendered` 一路涨到 19，大屏每 2s 闪一下白 | 尺寸与类型没变就走 `chart.options(spec) + render()` 增量更新 |
| 选中态用命令式 `classList.add` | 下一拍 innerHTML 重建就没了（标题切了、高亮没了） | 选中态由渲染拥有：在生成行 HTML 时写 class |
| `statsKind` 硬比 `'tasks'` | 106 的图永远不出 | 种子里是 `'task'` / `'testItems'`；出不出图统一跟 `viewProfile.blocks` 判据 |

## 4. 数据源与诚实口径

- 温湿度时序走 `GET /api/iot/temp-hum-series?node=&temp=&hum=&points=`（Mock）。
  **末点强制钉住请求带进来的当前读数**——图上最后一点和列表、区域面板的读数不是同一个数，客户一眼看穿是两套假数据。
  历史部分用「日周期曲线 + 节点指纹抖动」，同一小时内可重复，测试可独立重算。
- 温度(℃)与湿度(%RH)量纲不同，同图里各自归一后**只比趋势**，绝对值一律写进端点标签，不靠轴读数。
- 引擎来自 `twin/future-lab/vendor/g2.min.js`（1.08MB，随仓库走），**不依赖 CDN**：展厅断网也能开。
  加载失败或容器隐藏时数字表格照常显示——图表是读数的一种呈现，不是读数的唯一来源。

## 5. 性能

S1 七张图、下钻后最多九张，与 three.js 场景同屏：宿主 rAF 实测 **60fps**，`state.rendered` 稳定在 7（不再重建），
数据未变的图走签名跳过，变了走增量更新。心跳每 2s 一次，图表只在签名变化时重绘。

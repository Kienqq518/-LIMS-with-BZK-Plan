# UI 组件规格 V1（ui-components-spec.md）

> 输入：《视觉语言提取 V1.md》§2/§4 + 参考图；方法：threejs-game-ui-designer（层级/状态/区域/防错位原则）
> 通用铁律：① 组件只读单一数据源、只发意图不改状态；② 数值容器**固定宽度**（防跳动）；③ 每个可交互件必须有 hover/pressed/focus/disabled 四态；④ 用最长合理值做 text-fit 检查；⑤ 不嵌套卡片、不做营销式大 hero。

## 1. 悬浮数据卡（Beats 卡）
- 结构：`small 标签(11px/muted)` → `b 数值(26px/800) + em 单位(11px)` → sparkline(130×34，柱宽≈步长55%，透明度沿时间递增)。
- 锚定：`transform:translate(-50%,-100%)`，尖角对准设备上方世界坐标；连接线 2px 同色（接相机 API 后由世界坐标投影，禁止屏幕空间硬编码百分比——现为预览态妥协）。
- 状态：`valid` 正常 / `stale` 数值灰化+「数据延迟」/ `missing` 显示「—」不显示波形 / `offline` 整卡降饱和+「连接恢复后更新」。**诚实降级是组件级要求，不是页面级。**
- 尺寸：min-width 150px；padding 12/16/10；radius 14；shadow.tokens.card。

## 2. 标签组件（Grade 胶囊 / P 点 / 机器人胶囊）
- Grade 胶囊：高 22px，11px/700 白字，radius 999；A=#E5484D B=#F76B15 C=#F59E0B；下方 2px×14px 同色引线连到**贴地色块**（世界空间半透明矩形，描边 2px + 填充 8% + 外圈 10%）。
- P 目标点：26px 绿色圆角水滴（border-radius:50% 50% 50% 4px）+ 8px 淡绿外圈。
- 机器人胶囊：白底描边 + 16px 蓝色径向渐变光点（脉冲环 1.6s）+ 11px「复合机器人 · 前往 {目标}」；目标文本超出 12 字截断。

## 3. 数据气泡（安灯卡片 Andon Card）
- 结构：44×44 图标位（radius 12，#F1F5FB 底）→ 标题 14px（中英双语，中文为主）→ 原因行（8px 红点 + 12px 次级文字，单行截断）→ 动作区。
- 动作语义固定：主处理=蓝实心胶囊（安灯呼叫/已处置）；忽略=灰幽灵胶囊；胶囊高 28px、padding 6/14。
- 规则：同屏 Andon 卡 ≤3（超出进「告警抽屉」）；卡宽 236px 固定；出现用 cardIn 动效；关闭回落数据源状态而非本地隐藏。
- 分级派发（参考图4语义）：A→主任台+手机App；B→工位屏；C→运维队列。V1 演示版只展示派发目标标签，不做真实推送。

## 4. 导航栏（5M1E 维度胶囊）
- 位置：右上，top 18 / right 22；5 枚胶囊间距 8。
- 默认态：白底 + border #E3E9F2 + shadow.pill + 12px 文字 + 单色图标；**激活态：#2878FF 底白字**；hover 上浮 1px；focus-visible 走 ui-baseline 焦点环。
- 语义：切换场景叠加层（人=在场/授权，机=设备状态，料=样品/耗材，法=执行标准，环=环境/影像），与八维度对齐；激活维度决定 Beats 卡与 Grade 的过滤集。
- 键盘：←→ 切换，Enter 激活；aria-label「5M1E 维度切换」。

## 5. KPI 展示（左栏底部）
- 结构：`b 26px/800 带方向符(↑绿/↓蓝)` + `small 11px/muted 标签`；两组横排 gap 26。
- 数值容器固定宽 72px；count-up 200ms；方向语义优先（↑=改善绿，↓=下降蓝，与涨跌无关）。
- 数据源标注：KPI 下方 10px muted「近 24h · 采控系统」，诚实说明窗口。

## 6. 左栏品牌区 + 来源胶囊
- 左栏 300–480px（1920 取 300，2560+ 取上限）：logo(高26) + 品牌行 13px → 英文大标题 display 40/800 大写 → 蓝短杠 44×4 → 描述 13px/1.7 两行 → KPI → 底部来源胶囊。
- 来源胶囊：11px，#EAF1FF 底 #D7E4FF 边；未接入的源（如二期 LIMS）置灰态 `opacity:.55` + title 说明——**灰态即诚实降级**。

## 7. 响应式与大屏
- 基准 1920×1080；2560×1440 与 4K 用 `clamp()` 线性放大字号（display 34→44，卡片值 26→32），卡片尺寸不放大（保持信息密度）；场景视口占比不变。
- 安全边距 ≥22px；任何浮卡不得压住导航栏与左栏（z-index：导航9 > Andon5 > 浮卡4 > 描边3 > 轨迹2）。

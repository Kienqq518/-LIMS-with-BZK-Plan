## 2. 舞台改造中发现并修掉的两个缺陷

1. **弹窗随内容滚走**（本轮引入）：画布同时是滚动容器时，`fixed inset-0` 的包含块被滚动位移带偏，实测「查看历史」弹窗跑到 `y=-717`。改为双层结构：`#pa-canvas`（固定视口，不滚动）+ `#pa-scroll`（内容滚动），fixed 层提升到 canvas。复测 `delta=[0,0]` ✓
2. **隐藏的抽屉被提升后显形**（本轮引入）：`.export-drawer` 藏在 `display:none` 的遮罩里，被单独提升后脱离隐藏祖先，变成糊在画布上的白色浮层。现规则：祖先链有 `display:none` 的不提升；已随祖先进入画布的不重复提升；弹窗打开时再补一次提升。复测 canvas 直接子节点无残留浮层 ✓

另：`悬浮球在弹窗打开时被拉成整条横幅`（`.pa-toggle.pa-modal-open` 优先级不足）——上游 main 的 `46d6cac` 已修，本次 rebase 保留 main 的实现，我这边重复的补丁已丢弃。

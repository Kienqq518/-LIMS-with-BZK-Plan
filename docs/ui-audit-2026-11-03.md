## 2. 走查中发现并修掉的两个自伤缺陷（舞台改造过程）

1. **弹窗随内容滚走**：画布同时是滚动容器时，`fixed inset-0` 的包含块被滚动位移带偏，实测「查看历史」弹窗跑到 `y=-717`。改为双层结构：`#pa-canvas`（固定视口，不滚动）+ `#pa-scroll`（内容滚动），fixed 层提升到 canvas。复测 `delta=[0,0]` ✓
2. **隐藏的抽屉被提升后显形**：`.export-drawer` 藏在 `display:none` 的遮罩里，被单独提升后脱离隐藏祖先，变成糊在画布上的白色浮层。现规则：祖先链有 `display:none` 的不提升；已随祖先进入画布的不重复提升；弹窗打开时再补一次提升。复测 canvas 直接子节点无残留浮层 ✓

# 委托详情页 · 批量导出文件设计

**日期**: 2026-07-31  
**范围**: 委托详情页「委托单文件」→「原始记录表」及还样记录相关文件批量导出  
**状态**: 原型已落地；交互与范围规则如下（2026-07-31 增补还样两类表）

---

## 1. 目标

- 入口显眼：文件区顶部 sticky 高亮条「批量导出本委托文件」
- 范围可读：条上与弹窗内均写明「本委托 + 勾选类型 + 仅最新版 → ZIP」
- 类型可选：用户可勾选/全选需要的文件类型后再导出

## 2. 导出范围

| 维度 | 规则 |
|------|------|
| 对象 | 当前委托单 |
| 区块 | 「委托单文件」至「原始记录表」+「还样记录」中的退库确认表/退样申请表（不含开票记录等） |
| 版本 | 各类型**当前最新版**；历史版本不纳入（历史仅「查看历史」在线查看） |
| 空态 | 报告发放记录表 / 原始记录表 / 退样申请表等无文件时，勾选后导出阶段跳过 |
| 输出 | ZIP，按文件类型分子目录 |

## 3. 可选文件类型

1. 委托单文件  
2. 检测任务单  
3. 检测任务及样品流转单  
4. 收费通知单  
5. 报告文件  
6. 报告发放记录表  
7. 原始记录表  
8. 还样退库确认表（来自还样记录）  
9. 退样申请表（来自还样记录）  

说明：本页已去除「邮寄记录表」，故不在导出类型中。

## 4. 与版本管理的关系

- 批量导出取各类型 current 最新版，不暴露历史链下载
- 版本号语义、系统/人工落版、历史可见性见 `2026-07-29-entrust-doc-versioning-design.md`

# 委托详情页 · 批量导出文件设计

**日期**: 2026-07-31  
**范围**: 委托详情页「委托单文件」→「原始记录单」及还样记录相关文件批量导出  
**状态**: 原型已落地；交互与范围规则如下

---

## 1. 目标

- 入口显眼：置于「还样记录」上方的 sticky 高亮条「批量导出本委托文件」
- 范围可读：条上与弹窗内写明「本委托 + 勾选类型 + 仅最新版 → ZIP」
- 类型可选：用户可勾选/全选需要的文件类型后再导出
- **未生成类型置灰且不可勾选**（全选仅作用于已生成类型）

## 2. 导出范围

| 维度 | 规则 |
|------|------|
| 对象 | 当前委托单 |
| 区块 | 「委托单文件」至「原始记录单」+「还样记录」中的退库确认表/退样申请表（不含开票记录、报告发放记录表） |
| 版本 | 各类型**当前最新版**；历史版本不纳入（历史仅「查看历史」在线查看） |
| 空态 | 未生成的类型置灰且不可勾选（如退样申请表暂无文件） |
| 输出 | ZIP，按文件类型分子目录 |

## 3. 可选文件类型

1. 委托单文件  
2. 检测任务单（同一委托下各检测员任务单最新版一并打包）  
3. 检测任务及样品流转单  
4. 收费通知单  
5. 报告文件  
6. 原始记录单  
7. 还样退库确认表（来自还样记录）  
8. 退样申请表（来自还样记录）  

说明：本页已去除「邮寄记录表」；**报告发放记录表不纳入批量导出**（页面区块可仍保留展示）。

## 4. 分区批量下载

- 「报告文件」「原始记录单」各自提供「批量下载」按钮
- **仅当该区域内文件数 ≥ 2 时显示**；与页顶跨类型批量导出区分

## 5. 与版本管理的关系

- 批量导出取各类型 current 最新版，不暴露历史链下载
- 版本号语义、系统/人工落版、历史可见性见 `2026-07-29-entrust-doc-versioning-design.md`

# 报告模版 / 公共模版 文案与引用正文设计

**日期**: 2026-07-27  
**范围**: 模板管理 › 报告模版（原正文模板 + 公共头尾模板）  
**状态**: 已确认，原型更新中

## 背景

业务希望弱化「正文 / 头尾」对立命名，统一为：

- 二级 Tab：**报告模版**（原「正文模板」）与 **公共模版**（原「公共头尾模板」）
- 公共库除头/尾外，新增 **正文** 内容样式，供报告模版变体以「引用」方式共用

## 文案变更

| 原 | 新 |
|----|----|
| 正文模板 | 报告模版 |
| 公共头尾模板 / 公共头尾模版 | 公共模版 |
| 新增/编辑公共头尾模板 | 新增/编辑公共模版 |
| 模板文件（报告变体弹窗内） | 模版正文文件 |

相关落地页描述、系统参数说明、引导批注同步更新。

## 公共模版：内容样式「正文」

`模版内容样式` 选项：`模板头` | `模板尾` | `正文`

- 筛选、新增/编辑弹窗、列表展示均支持
- 头/尾自动匹配逻辑不变，仍只匹配头尾

## 公共模版：正文关联绑定约束

内容样式为 **正文** 时：

| 规则 | 说明 |
|------|------|
| 关联绑定维度 | **仅**「样品名称(型号)」；隐藏/禁用「样品分类」 |
| 绑定对象 | 支持 **下拉多选**（触发器样式与普通下拉一致，展开后勾选；同一正文可覆盖多个样品/型号） |
| 头/尾 | 仍可选「样品分类」或「样品名称(型号)」，普通下拉单选 |

数据字段：`bindType` 固定为 `sample`；`bindValues[]` / `bindLabels[]` 存多选结果（`bindValue` / `bindLabel` 冗余为首项，便于兼容展示）。

**不做**：在公共正文模版内再嵌套绑定公共头/尾。头尾归属报告模版变体层引用，避免正文与头尾双向缠绕、职责混乱。

## 公共模版：版本管理

- 操作列：`编辑 | 版本 | 配置 | 预览 | 删除`（三类样式均显示「版本」）
- 数据：每条公共模版含 `templates[]`，多版单启用（与报告变体版本一致）
- `file` 冗余为当前启用版本文件名

## 报告模版变体：正文来源「引用」

新增弹窗「模版正文文件」三选一：

1. **上传** — 本地上传，作为首个版本  
2. **复制** — 从其他报告变体复制文件  
3. **引用** — 下拉选择公共库中 `contentStyle === '正文'` 的模版；文件名只读回填

### 活引用语义

- 变体存 `refPublicId`
- 列表「当前启用版本」展示被引用公共模版的**当前启用文件**
- 公共正文版本变更后，引用该正文的报告变体展示同步变化

### 编辑策略（推荐）

编辑时**始终展示**「模版正文文件」区，按来源区分职责：

| 当前来源 | 编辑行为 |
|----------|----------|
| 本地（上传/复制） | 不在此改文件实体；提示走操作列「版本」。可切换为「引用」 |
| 引用 | 可改下拉目标；文件名只读。可切换为上传/复制转为本地 |

操作列「版本」：

- 本地变体 → 打开本变体版本弹窗  
- 引用变体 → 打开被引用**公共模版**的版本弹窗（版本归属公共侧）

## 数据模型增量

### BODY_DATA 变体

| 字段 | 说明 |
|------|------|
| refPublicId | 可选；有值表示活引用公共正文，此时 `templates` 为空或不参与启用 |

### PUBLIC_DATA

| 字段 | 说明 |
|------|------|
| contentStyle | `模板头` / `模板尾` / `正文` |
| bindType | `category` / `sample`；正文仅允许 `sample` |
| bindValues / bindLabels | 绑定对象多值（正文必用；头尾可单值） |
| bindValue / bindLabel | 冗余首项，兼容旧展示与匹配 |
| templates[] | 版本列表：name / time / enabled / uploader |

# 页眉页脚配置整改设计

**日期**: 2026-07-16  
**范围**: 页眉页脚从模板管理迁移至业务流程配置，并增加总开关与按文件类型细配  
**状态**: 已实现（原型）

## 背景与目标

原页眉页脚位于「模板管理 › 页眉页脚」，采用「全局默认 + 按单据类型覆盖」两级模型，且无启用开关。

业务诉求：

- 一套系统按项目交付给一个检测机构（租户），页眉页脚为该机构级配置
- 部分机构完全不需要页眉页脚
- 各导出文件类型需独立控制页眉、页脚是否启用
- 配置入口迁至「业务流程配置」

## 信息架构

### 业务流程配置 Tab 顺序

承检方信息 → 流程设置 → 委托信息设置 → **页眉页脚** → 记录单设置 → 报告设置 → 编号规则

进入页面默认激活 **承检方信息**。

### 模板管理

Landing 保留 3 张卡片：报告模版 / 记录单模版 / 单据模版。移除页眉页脚入口。

### 与公共头尾模板的边界

| | 页眉页脚（本功能） | 公共头尾模板 |
|--|-------------------|--------------|
| 形态 | PNG/JPG 图片 | Word 文档片段 |
| 作用 | 每页边距叠加 | 报告正文前后结构化内容 |
| 配置位置 | 业务流程配置 › 页眉页脚 | 模板管理 › 报告模版 |
| 适用范围 | 报告、记录单、7 类单据 | 仅报告正文拼接 |

## UI 设计

### 页眉页脚 Tab 结构

1. **说明条**：图片页眉页脚与公共头尾 Word 模版互不影响
2. **功能开关**：机构级总开关「启用页眉页脚」；关闭后下方置灰，配置保留
3. **默认页眉 / 页脚**：上传默认图片；各类型未上传专用图时继承
4. **按文件类型配置**：9 种固定类型，页眉/页脚独立 Toggle + 状态 + 操作

### 文件类型（9 种）

| key | 显示名 |
|-----|--------|
| `report` | 检测报告 |
| `record` | 记录单 |
| `entrust` | 检测委托书 |
| `fee_notice` | 收费通知单 |
| `task` | 检测任务单 |
| `task_flow` | 检测任务及流转单 |
| `return_confirm` | 还样退库确认表 |
| `return_apply` | 退样申请表 |
| `pre_notice` | 产品检测预通知书 |

不按业务大类（DLWZ/AQGQJ 等）区分。

### 状态文案

| 条件 | 页眉/页脚列显示 |
|------|----------------|
| 总开关关，或该侧开关关 | 不启用（灰） |
| 开关开 + 有专用图 | 文件名（蓝链） |
| 开关开 + 无专用图 + 有默认图 | 继承默认 |
| 开关开 + 无专用图 + 无默认图 | 未配置 |

### 交互规则

| 场景 | 行为 |
|------|------|
| 总开关关 | 默认区、表格置灰不可操作；已保存状态保留 |
| 文件类型侧开关关 | 导出时不叠加该侧；专用图保留 |
| 上传专用图 | 不自动打开对应开关 |
| 行内「恢复默认」 | 清除该行专用图；不改变开关 |
| 底部「恢复默认」 | 二次确认 → 总开关开、默认图清空、9 行开关全开、专用图全清 |
| 默认未上传 + 开关开 | 该侧不叠加，不阻断导出 |

上传约束与承检方签名印章一致：PNG/JPG，建议宽 ≥ 800px，单文件 ≤ 2MB。

## 数据模型

```javascript
HeaderFooterConfig = {
  enabled: boolean,
  defaultHeader: FileRef | null,
  defaultFooter: FileRef | null,
  fileTypes: {
    [fileTypeKey]: {
      headerEnabled: boolean,
      footerEnabled: boolean,
      headerOverride: FileRef | null,
      footerOverride: FileRef | null
    }
  }
}
```

一套部署一条配置，隐含当前检测机构租户。

## 导出解析逻辑

```
resolveSide(side, config, fileTypeKey):
  if !config.enabled → null
  if side 对应开关关 → null
  if 有专用图 → 专用图
  if 有默认图 → 默认图
  → null
```

页眉、页脚独立解析。

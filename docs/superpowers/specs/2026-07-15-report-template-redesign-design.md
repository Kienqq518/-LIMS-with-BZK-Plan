# 报告模板整改设计

**日期**: 2026-07-15  
**范围**: 模板管理 › 报告模板（正文模板 + 公共头尾模板）  
**状态**: 已确认，原型已更新（模板管理侧）

## 背景与目标

当前报告正文模板以「样品 + 型号 + 试验项组合」为维度配置，同一型号下多个模板靠不同试验项组合区分。业务需要改为：

- **一个样品 + 一个型号可配置多个报告模板变体**（如标准版、英文版、简版）
- **报告生成时由用户选择使用哪个模板**，默认选中「默认模板」
- **模板与委托试验项解耦**：模板内预置全部试验项占位；委托缺少的试验项在生成时不渲染（属模板 PageOffice 特殊技术配置，不在本结构设计中体现）
- **公共头尾模板**保持公共库定位，仅由正文模板变体引用

## 数据模型

### 正文模板变体（Body Template Variant）

| 字段 | 说明 |
|------|------|
| id | 主键 |
| tree / sample / category | 所属型号树节点、样品名称(型号)、样品分类 |
| name | 模板名称/别名（如「标准版」「英文版」） |
| isDefault | 是否为该型号下的默认模板（同型号仅一个 true） |
| head / tail | 引用的公共模版头/尾文件名，未引用为「—」 |
| file | 当前启用版本的文件名（冗余，便于列表展示） |
| templates[] | 版本列表，每项含 name、time、enabled |

**约束**:
- 同一样品+型号下可有 N 个变体，其中恰好 1 个 `isDefault = true`
- 每个变体内部可有多个版本，**同时仅启用一个**
- 引用公共头尾挂在**变体层**，该变体所有版本共用同一套头尾

### 公共头尾模板（Public Header/Footer）

结构基本不变：模板内容（头/尾）+ 作用范围（样品分类 或 样品名称型号，均可多选）+ 模板文件。

**微调**: 主列表操作列移除「上传」「复制」，上传与复制仅在新增/编辑弹窗内完成。

## 模板管理 UI（已实现原型）

### 正文模板 tab

**左树**: 大类 → 型号，括号内数字 = 该型号下模板变体数量。

**右表列**: 序号 / 模板名称 / 样品名称(型号) / 样品分类 / 默认 / 当前启用版本 / 引用公共模版头 / 引用公共模版尾 / 操作

**操作列**:
- 编辑：改名称、默认标记、头尾引用（不含文件）
- 版本：打开版本管理弹窗（多版单启用，复用记录单模式）
- 配置：PageOffice 编辑当前启用版本
- 预览
- 设为默认（已是默认则显示「已是默认」）
- 删除（默认变体需先切换默认）

**新增/编辑弹窗**:
- 样品名称(型号)、模板名称、设为默认、模板文件（上传/复制，作为首个版本）、引用公共头尾
- **已移除「试验项」字段**

**筛选**: 模板名称、样品、样品分类、文件名（已移除试验项筛选）

### 公共头尾模板 tab

- 操作列保留：编辑、配置、预览、删除
- **已移除**：上传、复制

## 报告生成侧（仅设计，未落原型）

**入口**: 报告管理 › 报告编制 › 编辑 › 检测信息 tab › 勾选样品 › 「生成报告」

**生成前增加模板选择步骤**:

1. 用户勾选样品后点击「生成报告」
2. 弹出模板选择（抽屉或弹窗），按样品+型号列出该型号下所有模板变体
3. **默认选中** `isDefault = true` 的变体，用户可切换其他变体
4. 确认后使用选中变体的**启用版本** + 其引用的公共头尾，将委托试验项数据填入模板生成报告
5. 生成结果展示在下方「报告文件」区域

**与记录单导出的差异**:
- 记录单：按试验项维度，有多试验项组合模版勾选
- 报告：按样品+型号维度，选模板变体（与试验项无关），一次生成一份完整报告

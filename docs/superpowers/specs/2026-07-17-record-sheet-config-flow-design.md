# 记录单配置流整改设计

**日期**: 2026-07-17  
**范围**: 业务流程配置 › 记录单设置、模板管理 › 记录单模版、试验检测 › 记录单导出抽屉  
**状态**: 已确认，待实现

## 背景与问题

当前记录单相关能力分散在三处，各自定义了一套「生成/导出模式」，彼此未贯通：

| 模块 | 现状问题 |
|------|---------|
| 记录单设置 | 4 种生成模式与导出抽屉、模版管理语义不对齐；配置后导出不生效 |
| 记录单模版 | 仅支持单试验项绑定 + 动态拼接；与导出抽屉「多试验项组合模版」概念冲突 |
| 导出抽屉 | 操作员重复做策略选择（单/多试验项、导出粒度）；缺模版导出时才报错 |

**决策**：采用配置驱动方案（方案 A），全部为**动态拼接**，不引入组合模版。

## 术语表

| 术语 | 含义 | 禁用/避免 |
|------|------|-----------|
| **样品分类** | 树形层级中的分类节点（如「安全工器具 › 绝缘操作杆」） | — |
| **样品名称(型号)** | 具体样品 + 型号，绑定模版与记录单规则的最小业务单元 | 与「试样」混称 |
| **试样** | 委托中某一型号下的单个检测对象实例（对应试样编号） | ~~试样实例~~ |
| **试验项** | 该型号需执行的检测项目（如「交流耐压试验」） | — |
| **生成模式** | 管理员在「记录单设置」中配置的切分规则 | ~~导出模式~~（操作员侧不再选择） |
| **动态拼接** | 导出时按实际完成的试验项，拉取各试验项启用模版并拼接为一个 Word 文件 | ~~组合模版~~ |

## 配置优先级

```
记录单设置（生成模式） > 记录单模版（单试验项模版） > 导出抽屉（仅预览与执行）
```

操作员**不能**在导出时覆盖管理员已配置的生成模式。

---

## 生成模式（4 种）

两个维度组合，共 4 种固定模式：

| # | 聚合维度 | 切分粒度 | 模式名称（UI 文案） | 导出结果 |
|---|---------|---------|-------------------|---------|
| 1 | 样品名称(型号) | 全部试验合并 | 单种样品所有试验生成一份文件 | 同一型号下，所有已完成试验项拼接 → **1 个文件** |
| 2 | 样品名称(型号) | 按试验项切分 | 单种样品单种试验生成一份文件 | 同一型号下，每个已完成试验项 → **各 1 个文件** |
| 3 | 试样 | 全部试验合并 | 单个试样所有试验生成一份文件 | 每个试样，其全部已完成试验项拼接 → **每试样 1 个文件** |
| 4 | 试样 | 按试验项切分 | 单个试样单种试验生成一份文件 | 每个试样 × 每个已完成试验项 → **各 1 个文件** |

> UI 文案说明：模式 1、2 中的「单种样品」指同一**样品名称(型号)**；模式 3、4 中的「单个试样」指委托中的单个**试样**（含试样编号），不再使用「单个样品」以免与型号混淆。

### 记录单设置 · 绑定规则

沿用现有「关联模式 + 绑定对象」结构：

| 字段 | 说明 |
|------|------|
| 关联模式 | `样品分类` 或 `样品名称(型号)` |
| 绑定对象 | 下拉选择具体分类或型号 |
| 生成模式 | 上表 4 种之一 |

**匹配优先级**（同一委托中多样品命中多条规则时）：

1. `样品名称(型号)` 精确匹配  
2. `样品分类` 匹配（取层级最近的一条）  
3. 系统默认：模式 2（单种样品单种试验生成一份文件）

**保存行为**：

- 保存时不做模版完整性预检（模版配置周期较长，不阻断规则保存）
- 校验仅限：绑定对象非空、同范围不重复配置

## 记录单模版（不变 + 澄清）

### 数据模型

维持现有「样品名称(型号) × 试验项 → 模版版本列表，单启用」结构，不做组合模版扩展。

### 导出拼接逻辑

用户导出时，系统按检测员**实际完成**的试验项，拉取各试验项**启用中**的模版，按固定顺序拼接为一个 Word 文件。

- 拼接顺序：与左侧树 / 试验项标准排序一致（非用户可选）
- 模式 1、3（全部试验合并）：一次导出触发一次拼接，缺任一试验项模版则**阻断该文件**
- 模式 2、4（按试验项切分）：每个文件仅含一个试验项模版，缺模版则**阻断该试验项对应文件**

### UI

- 移除或不再规划「组合模版」相关入口与说明
- 底部说明条保留并统一为动态拼接描述

## 导出抽屉（整改）

### 目标交互

打开抽屉 → **预览将生成的文件列表** → 确认导出。操作员不做策略配置。

### 移除

- 「单试验项生成一份 / 多试验项组合生成一份」两个折叠分区
- 「单种样品一起导出 / 单个试样单个文件」单选
- 「多试验项模版应用」列及勾选
- 试验项的手动勾选（改为只读展示）

### 保留

- 抽屉标题「记录单导出详情」
- 按文件粒度的列表 + 行内导出
- 底部「批量导出」

### 列表结构

| 列 | 说明 |
|----|------|
| 勾选 | 批量导出选择；缺模版的行默认不可勾选 |
| 文件名（预览） | 系统按生成模式自动生成，如 `SC2026/0052-0101_绝缘操作杆_交流耐压试验记录单.docx` |
| 样品名称(型号) | — |
| 试样编号 | 模式 3、4 显示；模式 1、2 显示「—」或「全部试样」 |
| 包含试验项 | 只读标签列表，仅展示已完成且将写入该文件的试验项 |
| 状态 | 就绪 / 缺模版（红色，注明缺哪几个试验项） |
| 操作 | 单行导出（就绪时可点） |

### 模版校验（导出时）

- **时机**：打开抽屉时计算；点击导出行或批量导出时再次校验
- **规则**：该文件所需的每个试验项均须存在启用中模版
- **缺模版表现**：
  - 行状态「缺模版」，展示如：`缺少「抗弯静负荷试验」的模版`
  - 该行勾选禁用、单行导出禁用
  - 批量导出跳过缺模版行；若全部不可导出则 toast 提示
- **不做**：受理、分配、记录单设置保存时的模版预检

### 文件预览生成算法（概要）

```
FOR each 样品名称(型号) in 当前委托:
  rule = resolveRecordRule(型号)   // 记录单设置匹配
  completedTests = 该型号下状态=已完成的试验项

  IF rule.聚合维度 == 样品名称(型号):
    IF rule.切分 == 全部试验合并:
      emit 1 file(型号, 全部 completedTests)
    ELSE:
      FOR each test in completedTests:
        emit 1 file(型号, [test])
  ELSE: // 试样维度
    FOR each 试样 in 该型号:
      IF rule.切分 == 全部试验合并:
        emit 1 file(试样, 全部 completedTests)
      ELSE:
        FOR each test in completedTests:
          emit 1 file(试样, [test])
```

未完成试验项不出现在「包含试验项」中；模式 1、3 若存在未完成试验项，文件仅含已完成部分（或业务可选：全部完成才允许导出——**默认允许部分导出，仅拼接已完成项**）。

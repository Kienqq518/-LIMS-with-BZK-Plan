# 编号规则整改设计方案

**日期**: 2026-07-28  
**范围**: 业务流程配置 › 编号规则；关联：样品分类（层级 1）、样品数据（试样类别代码）  
**状态**: 设计待确认（原型已同步演示：`system-params.html` › 编号规则）  
**参考**: 模板管理大类 Tab；样品分类「分类名称 / 分类编号 / 层级」

---

## 1. 背景与问题

| # | 现状 | 问题 |
|---|------|------|
| 1 | 编号规则全局一套 | 电力物资 / 安全工器具 / 环境检测 / 工程检测 业务编码习惯不同，无法各自配置 |
| 2 | 「添加令牌」扁平按钮墙 | 令牌语义混杂（日期、序号、引用、分隔符并列），难扫读、难扩展 |
| 3 | 前缀靠 `prompt`、年份拆成「年份(2位)/年份(4位)」两个令牌 | 同一语义拆多入口；位数等参数无法结构化配置 |
| 4 | 「类别名称 / 类别代码」命名与主数据不一致 | 样品分类已统一为「分类名称 / 分类编号」；且未限制层级 |
| 5 | 缺少「试样类别代码」 | 样品数据侧可按试验配置该码，编号规则无法引用 |
| 6 | 存在「客户编码」类型（线上/旧版） | 业务不再使用，应移除 |

---

## 2. 设计目标

1. **按样品大类分套配置**编号规则（对齐模板管理）。
2. **令牌按类型分组**；选择类型后展示**对应自定义字段**（非一刀切）。
3. 术语对齐样品分类：**分类名称 / 分类编号**，运行时仅取**层级 1**。
4. 新增令牌：**试样类别代码**（来源：样品数据 › 试验配置）。
5. **去除「客户编码」**。
6. 年份位数收敛为 **2 位 / 4 位** 二选一（不做任意位数步进）。

非目标：后端 API、历史编号回写、跨大类规则复制（可作为后续增强，见文末）。

## 3. 信息架构

### 3.1 Tab 页结构

```
业务流程配置 › 编号规则
├── [大类横向 Tab] 电力物资类 | 安全工器具类 | 环境检测 | 工程检测
├── 说明条（当前大类上下文）
└── 规则卡片列表（该大类下 6 类编号）
    ├── 委托编号规则
    ├── 委托单编号规则
    ├── 样品编号规则
    ├── 试验记录单编号规则
    ├── 原始记录单编号规则
    └── 报告编号规则
```

大类 key 与模板管理一致：`dlwz` / `aqgqj` / `hjjc` / `gcjc`。

### 3.2 切换大类

编号规则为**即时保存**（点弹窗「确定」即写入当前大类），切换大类**无需**未保存拦截（与模板管理「整页延迟保存」不同）。若后续改为整页保存，再复用模板管理的【保存 / 不保存 / 取消】。

## 5. 编辑弹窗（图 1 整改）

### 5.1 交互范式选择

| 方案 | 说明 | 结论 |
|------|------|------|
| A. 扁平令牌按钮 + prompt | 现状；参数能力弱 | 淘汰 |
| B. 仅分组调色板，点选即塞入固定令牌 | 扩展位数/分类仍困难 | 不够 |
| **C. 有序列表 + 类型下拉 + 条件字段** | 对齐图 3–10；每段可配参 | **采用** |

## 6. 令牌类型体系（对齐图 2，并做产品收敛）

### 6.1 下拉分组（添加令牌 / 类型选择）

| 分组 | 类型 | 自定义区 | 运行时取值 |
|------|------|----------|------------|
| **固定字符** | 指定字符 | 文本框（必填，建议 ≤ 20）；快捷芯片：`/` `-` `_` | 配置原文 |
| **委托日期** | 委托年份 | 单选：**2 位 / 4 位**（默认 4） | 委托创建/登记日期的年 |
| | 委托月份 | 无（固定 `MM`） | 同上 · 月 |
| | 委托日期 | 无（固定 `DD`） | 同上 · 日 |
| **送样日期** | 送样年份 | 单选：2 位 / 4 位 | 送样日期的年 |
| | 送样月份 | 无 | 月 |
| | 送样日期 | 无 | 日 |
| **分类与样品** | 分类名称 | 说明文案，无选项 | 样品所属分类树**层级 1**的名称 |
| | 分类编号 | 说明文案，无选项 | 层级 1 的编号（如 `DLDL`） |
| | 样品类型 | 说明文案（见 §6.3） | 样品数据中的样品类型字段 |
| | 试样类别代码 | 说明文案 | 样品数据中该**试验**配置的试样类别代码 |
| **序号** | 自增序号 | **序号位数**步进器，范围 2–8，默认 4；或快捷 2/3/4 | 按重置策略自增（见 §8） |
| **引用编号**（建议保留） | 委托编号 | 无 | 已生成的委托编号 |
| | 样品编号 | 无 | 已生成的样品编号 |
| | 行号 | 无（固定 2 位，可后续开放位数） | 委托明细行号 |

### 6.2 明确移除

- **客户编码**：类型列表与历史数据映射中删除；旧规则若含该令牌，打开编辑时提示「已废弃，请删除该段」。

### 6.3 「分类名称 / 分类编号」规则（图 11）

- 数据源：检测管理 › **样品分类** 的「分类名称」「分类编号」「层级」。
- **不在编号规则里挑选具体分类节点**；令牌是动态占位，生成时根据当前样品解析。
- **仅使用层级 = 1** 的节点（如「电力电缆类 / DLDL」）。理由：仅第一层在各大类内编码/命名口径统一；更深层级树形分叉，无法作为稳定编号段。
- 若样品未挂到分类、或层级 1 无编号：该段输出空字符串，预览用灰色占位「(无分类编号)」；保存规则不阻断，生成时打日志/告警（实现期定）。

### 6.4 「试样类别代码」

- 配置入口：**样品数据**（各大类明细）中，为每个**试验**维护「试样类别代码」。
- 编号规则令牌：生成时取「当前试验」已配置的代码；无试验上下文的单据（如纯委托编号）**不宜使用**该令牌——保存时校验并 toast 提示（见 §8）。

### 6.5 「样品类型」

与「试样类别代码」区分：

| 字段 | 粒度 | 典型用途 |
|------|------|----------|
| 样品类型 | 样品 / 型号侧属性 | 区分样品品类标签 |
| 试样类别代码 | **试验项**侧配置 | 进入编号的试验侧短码 |

若样品数据尚未落「样品类型」字段，原型用说明占位；实现前需在样品数据补齐字段定义（开放问题 Q1）。

### 6.6 与旧「扁平令牌」映射

| 旧令牌 | 新类型 + 参数 |
|--------|----------------|
| 前缀文本 | 指定字符 |
| 年份(4位) / 年份(2位) | 委托年份 + digits=4/2（语义默认归「委托」；若业务实为送样，需人工改类型） |
| 月份 / 日期 | 委托月份 / 委托日期 |
| 2/3/4 位自增序号 | 自增序号 + digits |
| 分隔符 / - _ | 指定字符（值为对应符号） |
| 委托编号 / 样品编号 / 行号 | 同名引用类型 |
| 类别名称 / 类别代码 | 分类名称 / 分类编号 |

## 7. 各类型自定义区明细（相对图 3–10 的优化）

| 类型 | 自定义区 | 相对参考图的调整 |
|------|----------|------------------|
| 指定字符 | `* 指定字符` 文本框；下方快捷：`/` `-` `_`「填入」 | 合并原「分隔符」三类令牌，减少入口 |
| 自增序号 | `* 序号位数` 数字步进 2–8 | 参考图步进器；下限 2，避免 0 |
| 委托/送样年份 | `* 年份位数`：**2 位 \| 4 位** 单选 | **不**用 0–N 步进；按你的反馈收敛 |
| 委托/送样月份、日期 | 仅类型，无额外字段 | 与图 6/7/9/10 一致 |
| 分类名称 / 分类编号 | 只读说明：「生成时取样品所属**层级 1**分类的名称/编号」 | 替代旧「类别*」；禁止选深层 |
| 样品类型 | 只读说明 | 待字段落库 |
| 试样类别代码 | 只读说明 + 链到样品数据配置指引 | 新增 |
| 引用类 | 无额外字段 | 保留业务链 |

切换类型时：**清空上一类型的参数**，写入新类型默认值（年份默认 4 位，序号默认 4 位，指定字符默认空）。

## 8. 校验与生成预览

### 8.1 保存校验

1. 至少 1 个令牌段。
2. 「指定字符」非空。
3. 「自增序号」位数 ∈ [2, 8]。
4. 年份位数 ∈ {2, 4}。
5. 同一规则内**至多一个**「自增序号」（避免双序列歧义）。
6. 单据上下文限制（建议）：
   - 委托编号规则：禁止「样品编号」「试样类别代码」等下游依赖。
   - 样品编号规则：可含「委托编号」；慎用「试样类别代码」。
   - 试验记录单 / 报告等：允许「试样类别代码」「样品编号」。

### 8.2 生成预览

- 使用当前大类下的 **Mock 样例上下文**（固定示例日期、层级 1 分类、试样类别代码等）实时拼接。
- 预览区保持浅绿提示条；无效段用 `?` 或灰色文案标出。

### 8.3 自增重置策略（实现约定，UI 本期不暴露）

默认：**按自然年 + 当前规则指纹 + 大类** 重置；位数不足时左侧补 0，溢出时位数自动扩展一位并告警（或拒绝生成——实现期二选一，建议告警并扩展）。

## 9. 数据模型

```javascript
// 按大类分套
NUMBERING_BY_CAT = {
  dlwz: { entrust: Rule, 'entrust-order': Rule, sample: Rule, ... },
  aqgqj: { ... },
  hjjc: { ... },
  gcjc: { ... }
}

Rule = {
  id: 'entrust',
  name: '委托编号规则',
  tokens: [
    { type: 'literal', value: 'SC' },
    { type: 'entrust_year', digits: 4 },
    { type: 'literal', value: '/' },
    { type: 'seq', digits: 4 }
    // { type: 'category_name' }           // 层级1 名称
    // { type: 'category_code' }           // 层级1 编号
    // { type: 'specimen_category_code' }  // 试样类别代码
    // { type: 'sample_type' }
    // { type: 'submit_year', digits: 2 }
    // { type: 'ref_entrust' } | ref_sample | row_no
  ]
}
```

类型枚举（建议）：

`literal` | `entrust_year` | `entrust_month` | `entrust_day` | `submit_year` | `submit_month` | `submit_day` | `category_name` | `category_code` | `sample_type` | `specimen_category_code` | `seq` | `ref_entrust` | `ref_sample` | `row_no`

## 10. 样品数据侧配合（试样类别代码）

本期编号规则只**消费**该字段。样品数据详情中需保证：

- 试验项可编辑「试样类别代码」（短文本 / 编码，建议 ≤ 16）。
- 空值时编号段为空，并在检测流程侧可观测。

若详情页尚未有该字段，单列需求：「样品数据 › 试验配置增加试样类别代码」——可与本设计同迭代或紧随其后。

---

## 11. 迁移与兼容

1. 全局旧规则 → 复制到四大类作为初始值（或仅复制到有业务的大类，其余用系统默认）。
2. 旧 token 按 §6.6 映射；无法映射的（客户编码）标记废弃。
3. 已发出的历史编号**不重算**；规则仅影响保存后新生成号码。

## 14. 验收要点

1. 四大类 Tab 切换后规则集独立，改 A 类不影响 B 类。
2. 弹窗类型下拉按分组展示；无「客户编码」。
3. 选「委托年份」仅出现 2/4 位；选「指定字符」出现文本框；选月份/日期无多余字段。
4. 「分类名称 / 分类编号」文案正确；说明标明仅层级 1；预览示例来自层级 1。
5. 存在「试样类别代码」类型；说明指向样品数据配置。
6. 生成预览随令牌增删改实时变化。
7. 确定后列表芯片与示例更新。

# 编号规则整改设计方案

**日期**: 2026-07-28  
**范围**: 业务流程配置 › 编号规则；关联：样品分类（层级 1）、样品数据（试样类别代码）  
**状态**: 设计已确认关键决策（原型已同步：`system-params.html` › 编号规则）  
**参考**: 模板管理大类 Tab；样品分类「分类名称 / 分类编号 / 层级」

---

## 1. 背景与问题

| # | 现状 | 问题 |
|---|------|------|
| 1 | 编号规则全局一套 | 电力物资 / 安全工器具 / 环境检测 / 工程检测 业务编码习惯不同，无法各自配置 |
| 2 | 「添加令牌」扁平按钮墙 | 令牌语义混杂（日期、序号、引用、分隔符并列），难扫读、难扩展 |
| 3 | 前缀靠 `prompt`、年份拆成「年份(2位)/年份(4位)」两个令牌 | 同一语义拆多入口；位数等参数无法结构化配置 |
| 4 | 「类别名称 / 类别代码」命名与主数据不一致 | 样品分类已统一为「分类名称 / 分类编号」；且未限制层级 |
| 5 | 缺少「试样类别代码」 | 样品数据侧可按试验配置该码，编号规则无法引用 |
| 6 | 存在「客户编码」类型（线上/旧版） | 业务不再使用，应移除 |

---

## 2. 设计目标

1. **按样品大类分套配置**编号规则（对齐模板管理）。
2. **令牌按类型分组**；选择类型后展示**对应自定义字段**（非一刀切）。
3. 术语对齐样品分类：**分类名称 / 分类编号**，运行时仅取**层级 1**。
4. 新增令牌：**试样类别代码**（来源：样品数据 › 试验配置）。
5. **去除「客户编码」「样品类型」「行号」**。
6. **日期**令牌级联：来源（委托登记日 / 送样日）→ 年/月/日 → 年再选 **2 / 4 位**。
7. **指定字符**拆为二级：自定义（输入框）/ 固定拼接符号（仅 `/` `-` `_`）。
8. **自增序号**仅保留 2 / 3 / 4 位快捷（无步进器）。
9. 新增 **报告数量**：维度（样品大类 / 样品分类层级1）+ 当年/当月 + 默认「拼接 +1」+ 3/4/5 位。
10. **保留引用编号**（委托编号 / 样品编号）。
11. 规则芯片预览区用本地 flex 固定住，避免浮层错位。

非目标：后端 API、历史编号回写、跨大类规则复制（可作为后续增强，见文末）。

## 3. 信息架构

### 3.1 Tab 页结构

```
业务流程配置 › 编号规则
├── [大类横向 Tab] 电力物资类 | 安全工器具类 | 环境检测 | 工程检测
├── 说明条（当前大类上下文）
└── 规则卡片列表（该大类下 6 类编号）
    ├── 委托编号规则
    ├── 委托单编号规则
    ├── 样品编号规则
    ├── 试验记录单编号规则
    ├── 原始记录单编号规则
    └── 报告编号规则
```

大类 key 与模板管理一致：`dlwz` / `aqgqj` / `hjjc` / `gcjc`。

### 3.2 切换大类

编号规则为**即时保存**（点弹窗「确定」即写入当前大类），切换大类**无需**未保存拦截（与模板管理「整页延迟保存」不同）。若后续改为整页保存，再复用模板管理的【保存 / 不保存 / 取消】。

## 6. 令牌类型体系（对齐图 2，并做产品收敛）

### 6.1 下拉分组（添加令牌 / 类型选择）

| 分组 | 类型 | 自定义区 | 运行时取值 |
|------|------|----------|------------|
| **指定字符** | 自定义 | 文本输入框（必填，≤ 20） | 配置原文 |
| | 固定拼接符号 | 仅快捷：`/` `-` `_`（必选其一，默认 `-`） | 所选符号 |
| **日期** | 日期 | 级联三步（见 §6.3） | 按来源 + 部分解析 |
| **分类与试样** | 分类名称 | 说明文案 | 样品所属分类树**层级 1**的名称 |
| | 分类编号 | 说明文案 | 层级 1 的编号（如 `DLDL`） |
| | 试样类别代码 | 说明文案（无「请勿使用」警告句） | 样品数据中该试验配置的试样类别代码 |
| **序号与数量** | 自增序号 | 仅快捷 **2 / 3 / 4 位**（默认 4，无步进器） | 按重置策略自增 |
| | 报告数量 | 见 §6.6 | 统计范围内已有报告数 **+1**，按位数补零 |
| **引用编号** | 委托编号 | 无 | 已生成的委托编号 |
| | 样品编号 | 无 | 已生成的样品编号 |

### 6.2 明确移除

- **客户编码**、**样品类型**、**行号**。
- 旧规则含行号时打开编辑自动剔除该段。

### 6.3 「日期」令牌：级联配置（已确认）

类型下拉只出现一项 **日期**；选中后自定义区按顺序展开：

```
* 日期来源   ( ) 委托日期   ( ) 送样日期
* 日期部分   ( ) 年         ( ) 月       ( ) 日
* 位数       ( ) 2位        ( ) 4位      ← 仅当「日期部分 = 年」时出现
```

| 字段 | 选项 | 说明 |
|------|------|------|
| 日期来源 | 委托日期 / 送样日期 | **委托日期** = 委托**登记**日期；送样日期 = 送样日期字段 |
| 日期部分 | 年 / 月 / 日 | 月、日固定输出 `MM` / `DD`（2 位补零） |
| 位数 | 2 位 / 4 位（默认 4） | **仅「年」需要**；选月/日时隐藏本行 |

芯片文案示例：`委托日期·年·4位`、`送样日期·月`。

### 6.4 「分类名称 / 分类编号」规则（图 11）

- 数据源：检测管理 › **样品分类** 的「分类名称」「分类编号」「层级」。
- **不在编号规则里挑选具体分类节点**；令牌是动态占位，生成时根据当前样品解析。
- **仅使用层级 = 1** 的节点（如「电力电缆类 / DLDL」）。
- 若样品未挂到分类、或层级 1 无编号：该段输出空字符串；保存规则不阻断。

### 6.5 「试样类别代码」

- 配置入口：**样品数据**中为每个试验维护「试样类别代码」。
- 提示文案仅说明数据来源，**不含**「无试验上下文的单据请勿使用本令牌」。

### 6.6 「报告数量」（新增）

| 字段 | 选项 | 说明 |
|------|------|------|
| 统计维度 | **样品大类** / **样品分类（层级1）** | 仅此两种 |
| 统计范围 | **当年** / **当月** | — |
| 数值处理 | 固定展示 **拼接 +1** | 表示该维度在范围内已有报告数 +1（第 N 份）；不可改 |
| 指定位数 | 快捷 **3 / 4 / 5 位**（默认 4） | 无步进器 |

### 6.7 芯片浮层修复

列表 `.num-rule` 与弹窗 `#ruleChipPreview` 使用本地 CSS `display:flex; flex-wrap; overflow:hidden; isolation:isolate`，芯片 `position:static`，不依赖 Tailwind CDN，避免「指定字符」芯片漂出容器。

### 6.8 与旧「扁平令牌」映射

| 旧令牌 | 新类型 + 参数 |
|--------|----------------|
| 前缀文本 / 任意指定字符 | 自定义 |
| 分隔符 / - _ | 固定拼接符号 |
| 年份/月份/日期 | 日期令牌级联 |
| 2/3/4 位自增 | 自增序号 + digits |
| 委托编号 / 样品编号 | 同名引用 |
| 行号 / 客户编码 / 样品类型 | **废弃** |
| 类别名称 / 类别代码 | 分类名称 / 分类编号 |

## 7. 各类型自定义区明细（相对图 3–10 的优化）

| 类型 | 自定义区 | 相对参考图的调整 |
|------|----------|------------------|
| 指定字符 | `* 指定字符` 文本框；下方快捷：`/` `-` `_`「填入」 | 合并原「分隔符」三类令牌，减少入口 |
| **日期** | ① 日期来源 ② 日期部分 ③（年时）位数 2/4 | **级联**，不再平铺 6 个类型；位数不用步进 |
| 自增序号 | `* 序号位数` 数字步进 2–8 | 参考图步进器；下限 2，避免 0 |
| 分类名称 / 分类编号 | 只读说明：「生成时取样品所属**层级 1**分类的名称/编号」 | 替代旧「类别*」；禁止选深层 |
| 试样类别代码 | 只读说明 + 链到样品数据配置指引 | 新增 |
| 引用类 | 无额外字段 | **已确认保留** |

切换类型时：**清空上一类型的参数**，写入新类型默认值（日期默认：委托日期 + 年 + 4 位；序号默认 4 位；指定字符默认空）。

## 8. 校验与生成预览

### 8.1 保存校验

1. 至少 1 个令牌段。
2. 「指定字符」非空。
3. 「自增序号」位数 ∈ [2, 8]。
4. 「日期」：来源、部分必填；部分=年时位数 ∈ {2, 4}。
5. 同一规则内**至多一个**「自增序号」（避免双序列歧义）。
6. 单据上下文限制（建议）：
   - 委托编号规则：禁止「样品编号」「试样类别代码」等下游依赖。
   - 样品编号规则：可含「委托编号」；慎用「试样类别代码」。
   - 试验记录单 / 报告等：允许「试样类别代码」「样品编号」。

### 8.2 生成预览

- 使用当前大类下的 **Mock 样例上下文**（固定示例委托登记日 / 送样日、层级 1 分类、试样类别代码等）实时拼接。
- 预览区保持浅绿提示条；无效段用 `?` 或灰色文案标出。

### 8.3 自增重置策略（实现约定，UI 本期不暴露）

默认：**按自然年 + 当前规则指纹 + 大类** 重置；位数不足时左侧补 0，溢出时位数自动扩展一位并告警（或拒绝生成——实现期二选一，建议告警并扩展）。

## 9. 数据模型

```javascript
// 按大类分套
NUMBERING_BY_CAT = {
  dlwz: { entrust: Rule, 'entrust-order': Rule, sample: Rule, ... },
  aqgqj: { ... },
  hjjc: { ... },
  gcjc: { ... }
}

Rule = {
  id: 'entrust',
  name: '委托编号规则',
  tokens: [
    { type: 'literal', value: 'SC' },
    { type: 'date', source: 'entrust', part: 'year', digits: 4 },
    { type: 'literal', value: '/' },
    { type: 'seq', digits: 4 }
    // { type: 'category_name' }
    // { type: 'category_code' }
    // { type: 'specimen_category_code' }
    // { type: 'date', source: 'submit', part: 'month' }
    // { type: 'ref_entrust' } | ref_sample | row_no
  ]
}
```

类型枚举（建议）：

`literal` | `date` | `category_name` | `category_code` | `specimen_category_code` | `seq` | `ref_entrust` | `ref_sample` | `row_no`

`date` 附加字段：`source: 'entrust' | 'submit'`，`part: 'year' | 'month' | 'day'`，`digits?: 2 | 4`（仅 year）。

## 10. 样品数据侧配合（试样类别代码）

本期编号规则只**消费**该字段。样品数据详情中需保证：

- 试验项可编辑「试样类别代码」（短文本 / 编码，建议 ≤ 16）。
- 空值时编号段为空，并在检测流程侧可观测。

若详情页尚未有该字段，单列需求：「样品数据 › 试验配置增加试样类别代码」——可与本设计同迭代或紧随其后。

---

## 11. 迁移与兼容

1. 全局旧规则 → 复制到四大类作为初始值（或仅复制到有业务的大类，其余用系统默认）。
2. 旧 token 按 §6.6 映射；无法映射的（客户编码、样品类型）标记废弃。
3. 已发出的历史编号**不重算**；规则仅影响保存后新生成号码。

## 13. 已确认结论 / 剩余开放问题

| ID | 问题 | 结论 |
|----|------|------|
| Q1 | 是否做「样品类型」令牌？ | **不做** |
| Q2 | 「委托日期」取哪个字段？ | **委托登记日期** |
| Q3 | 日期交互如何组织？ | **先选来源（委托/送样）→ 再选年/月/日 → 年再选 2/4 位** |
| Q4 | 是否保留「引用编号」？ | **保留**委托编号 / 样品编号；**去除行号** |
| Q5 | 「指定字符」如何拆分？ | 二级：**自定义**（输入框）/ **固定拼接符号**（/ - _） |
| Q6 | 「报告数量」统计维度？ | 仅 **样品大类**、**样品分类（层级1）**；范围当年/当月；数值处理固定「拼接 +1」；位数 3/4/5 |

## 14. 验收要点

1. 四大类 Tab 切换后规则集独立，改 A 类不影响 B 类。
2. 弹窗类型下拉按分组展示；无「客户编码」、无「样品类型」。
3. 选「日期」出现来源 → 部分 →（年时）位数；选「指定字符」出现文本框。
4. 「分类名称 / 分类编号」文案正确；说明标明仅层级 1；预览示例来自层级 1。
5. 存在「试样类别代码」类型；说明指向样品数据配置。
6. 「引用编号」分组含委托编号 / 样品编号 / 行号。
7. 生成预览随令牌增删改实时变化；确定后列表芯片与示例更新。

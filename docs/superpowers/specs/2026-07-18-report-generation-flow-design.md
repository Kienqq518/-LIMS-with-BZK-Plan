## 背景与决策

报告生成涉及两类「默认值」：

1. **导出模式** — 单种样品一份报告 / 单个样品一份报告  
2. **报告模版变体** — 标准版 / 英文版 / 简版等  

经讨论确定采用 **「管理员配默认 + 编制员可改 + 确认后导出」** 模式：

- 管理员在 **报告设置** 按大类或样品配置**默认导出模式**
- 管理员在 **报告模版** 按型号标记**默认模版变体**（已有）
- 编制员生成时，两项均**预填默认值**，但**均可修改**
- 确认导出模式与模版后，执行生成

### 与记录单配置流的差异

| 维度 | 记录单 | 报告 |
|------|--------|------|
| 策略默认值 | 管理员在「记录单设置」配置 | 管理员在「报告设置」配置 |
| 操作员能否改策略 | **不可改** | **可改**（预填默认，允许覆盖） |
| 勾选范围 | 导出抽屉只读预览 | 编制员勾选本次生成试样 |
| 模版 | 按试验项动态拼接 | 选模版变体（预填默认，允许覆盖） |

## 术语

| 术语 | 含义 |
|------|------|
| 样品分类 / 大类 | 如电力物资类、安全工器具类 |
| 样品名称(型号) | 如「实壁塑料电缆导管 PVC-C」 |
| 试样 | 委托中某一型号下的单个检测对象（含试样编号） |
| 默认导出模式 | 报告设置中绑定的 2 选 1 模式 |
| 默认模版变体 | 报告模版管理中 `isDefault = true` 的变体 |

## 默认导出模式（2 选 1）

| key | 模式名称 | 行为 |
|-----|---------|------|
| `model-batch` | **单种样品一份报告** | 当前勾选的全部试样 → **1 份**报告 |
| `specimen-each` | **单个样品一份报告** | 当前勾选的每个试样 → **各 1 份**报告 |

> UI 文案与图 1 原型对齐：「单种样品一起导出 / 单个样品单个文件」可映射为上述两种模式，实现时统一用语即可。

## 业务流程配置 › 报告设置

### 新增：默认导出模式绑定规则

参照 **记录单设置** 的「关联模式 + 绑定对象 + 生成模式」结构，新增绑定规则表：

| 字段 | 说明 |
|------|------|
| 关联模式 | `样品分类` / `样品名称(型号)` |
| 绑定对象 | 具体大类或型号 |
| 默认导出模式 | `单种样品一份报告` / `单个样品一份报告` |

**匹配优先级**（生成时解析默认值）：

1. `样品名称(型号)` 精确匹配  
2. `样品分类` 匹配（取层级最近的一条）  
3. 系统兜底：`specimen-each`（单个样品一份报告）

**保存校验**：

- 绑定对象非空、同范围不重复配置
- **不做**模版完整性预检

**建议初始种子**：

| 绑定 | 默认模式 |
|------|---------|
| 电力物资类 | 单种样品一份报告 |
| 安全工器具类 | 单种样品一份报告 |
| 环境检测 | 单种样品一份报告 |
| 工程检测 | 单种样品一份报告 |

### 保留：全局组装规则

| 配置项 | 说明 |
|--------|------|
| 骑缝章生成阶段 | 报告审核 / 报告签发 / 报告发放 |
| 报告中是否添加收样图片 | 是 / 否 |
| 头部—内容是否加换页符 | 是 / 否 |
| 内容—尾部是否加换页符 | 是 / 否 |

## 报告编制 › 报告生成编辑页

### 入口

报告管理 › 报告编制列表 › 「报告生成」→ 报告生成编辑页（检测信息 tab）。

### 页面结构

1. **样品信息**（只读）
2. **检测项目勾选表** — 编制员勾选本次参与生成的试样
3. **导出方式**（单选，**预填报告设置默认值，可修改**）
   - 单种样品一份报告
   - 单个样品一份报告
4. **生成报告** 按钮
5. **报告文件** 区

### 生成流程

```
勾选试样
  → 点击「生成报告」
  → 弹出「生成确认」抽屉/弹窗，含两项可改设置：
       ① 导出方式（预填：报告设置解析出的默认模式）
       ② 模版变体（预填：模版管理中 isDefault 变体；涉及多型号时分开展示）
  → 用户确认（可修改后再确认）
  → 校验：每个涉及型号须有变体且存在启用版本
  → 缺模版则阻断：「实壁塑料电缆导管 PVC-C 缺少报告模版！」
  → 生成 Word 报告 → 写入「报告文件」列表
```

### 生成确认弹窗（核心交互）

| 区块 | 预填来源 | 可否修改 |
|------|---------|---------|
| 导出方式 | 报告设置绑定规则 | **可改** |
| 模版变体 | 报告模版 `isDefault` | **可改** |

- 单型号委托：一行模版选择即可  
- 多型号委托：按型号分组，每组独立选变体（各预填各自默认）  
- 底部按钮：**取消** / **确认生成**

### 报告文件区

| 列 | 说明 |
|----|------|
| 序号 | — |
| 报告编号 | 系统生成 |
| 试样编号 | 合并导出时可为多个或「—」 |
| 报告 | 文件名链接 |
| 生成时间 | — |
| 修改时间 | 添加报告图片后更新 |
| 操作 | 添加报告图片、导出 PDF |

**添加报告图片**：报告生成后、正式编制提交前可用。

### 缺模版校验

- **时机**：确认生成时  
- **规则**：涉及型号无变体或无启用版本 → 阻断并提示  
- **不做**：报告设置保存时预检

## 配置优先级总览

```
报告设置（默认导出模式） ──预填──→ 生成确认弹窗（可改）
报告模版（默认变体）     ──预填──→ 生成确认弹窗（可改）
编制员勾选试样           ──决定──→ 本次生成范围
确认后                   ──执行──→ 生成报告文件
```

## 示例（PVC-C）

报告设置：「PVC-C」→ 单种样品一份报告  
报告模版：「标准版」= 默认  

编制员勾选 3 试样 → 生成报告 → 确认弹窗预填「单种样品一份 + 标准版」→ 确认 → 输出 1 份 `report_name.docx`。

若改为「单个样品一份 + 英文版」并确认 → 输出 3 份英文版报告。

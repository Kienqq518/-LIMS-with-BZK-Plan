## 规则台账（Base）设计

**表名**：`AI 审核规则台账`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 规则ID | 文本 | A01-1 … C02-5 |
| 规则组 | 单选 | A01/A02/A03/B01/B02/B03/C01/C02 |
| 类别 | 单选 | A 数据完整性 / B 逻辑一致性 / C 格式规范性 |
| 判定式 | 文本 | 伪代码，如 `abs(v1-v2)/mean ≤ 10%` |
| 所需字段 | 多选/文本 | 对应 3.7 字段依赖 |
| 标准依据 | 文本 | GB/T 1231-2010、DL/T 976-2017、GB/T 8170 … |
| 严重度 | 单选 | 严重 / 一般 / 轻微 / 提示 |
| 适用领域 | 多选 | 电网物资 / 安全工器具 / 通用 |
| 状态 | 单选 | 待审核员确认 / 已确认 / 已上线 / 停用 |
| 版本 | 文本 | 默认 v0.1 |
| 负责人 | 文本 | 角色名 |
| 备注 | 文本 | — |

**拆分口径**（44 条，从 3.2.1 检查项逐条拆出）：A01 6 + A02 5 + A03 6 = **17**；B01 5 + B02 8 + B03 4 = **17**；C01 5 + C02 5 = **10**。差额 6 条留 M1 Week 1 调研后补齐，正文与台账同时写明，不虚报 50 条。**口径固定：44 = 台账当前存量，≥50 = M1 出口目标，二者不构成矛盾；任何位置提及都必须带其中一个限定词。**

**初始状态**：全部「待审核员确认」——判定式由文档描述推导，未经审核员验证。

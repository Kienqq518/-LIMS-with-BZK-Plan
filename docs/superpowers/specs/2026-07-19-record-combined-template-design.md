# 记录单组合模版设计

**日期**: 2026-07-19  
**范围**: 模板管理 › 记录单模版、试验检测 › 记录单导出抽屉（模版解析部分）  
**状态**: 已实现（原型）  
**实现计划**: [`2026-07-19-record-combined-template-plan.md`](../plans/2026-07-19-record-combined-template-plan.md)  
**前置文档**: [`2026-07-17-record-sheet-config-flow-design.md`](2026-07-17-record-sheet-config-flow-design.md)

## 背景

现有记录单模版仅支持 **样品名称(型号) × 试验项** 单模版绑定；合并类导出依赖各试验项模版动态拼接。本次扩展 **样品层 / 型号层组合模版**（一份 Word 含该范围内全部试验项），与试验项单模版并存，导出时按生成模式自动选择来源。

**不在本次范围**：分类层上传组合模版、复制弹窗改造、后端 API。

---

## 已确认决策摘要

| 议题 | 决策 |
|------|------|
| 绑定层级 | **样品层 + 型号层** 可上传；**分类层不上传** |
| 页面布局 | 上下分区：组合模版卡片 + 统一表格（A 方案） |
| 导出分流 | 合并类模式用组合模版（导出时解析继承）；切分类模式始终用试验项单模版 |
| 继承链（仅导出时） | **型号层 > 样品层**（不含分类层） |
| 继承 UI | **不展示**；模版文件列仅 `xxx.docx` / `未上传` |
| 是否已配置 | 本节点实际上传了启用中文件 = 已配置；依赖上级继承 = **未配置** |

## 术语表

| 术语 | 含义 |
|------|------|
| **样品层** | 树中直接包含 ≥1 个 `model:true` 子节点的节点（`sample:true`），如 `DS实壁类塑料电缆导管_直管` |
| **型号层** | `model:true` 节点，如 `PVC-C` |
| **组合模版** | 绑定样品层或型号层，一份 Word 含该绑定范围内全部试验项占位 |
| **试验项单模版** | 现有 `RECORD_DATA` 行，一试验项一模版 |
| **动态拼接** | 无可用组合模版时，拉取各试验项启用模版拼接为一个 Word |

### 生成模式（UI 全文案）

| 模式 | UI 文案 |
|------|---------|
| 合并 · 按型号 | **单种样品所有试验生成一份文件** |
| 切分 · 按型号 | **单种样品单种试验生成一份文件** |
| 合并 · 按样品实例 | **单个样品所有试验生成一份文件** |
| 切分 · 按样品实例 | **单个样品单种试验生成一份文件** |

> 后两种模式名称使用「单个**样品**」，与 [`2026-07-17`](2026-07-17-record-sheet-config-flow-design.md) 中「单个试样」表述对齐为本设计采用的 UI 文案。

## 数据模型

### 组合模版（新增 `RECORD_COMBINED_DATA`）

```javascript
{
  id: 1,
  bindType: 'sample' | 'model',   // 不含 category
  bindTarget: 'ds-s',             // 树节点 id
  bindLabel: 'DS实壁类塑料电缆导管_直管',
  file: '实壁导管_全套记录单.docx', // null 表示未上传
  configured: false,              // 仅本节点实际上传时为 true
  templates: [
    { name: '...', time: '...', enabled: true, uploader: 'admin' }
  ]
}
```

- 版本规则与试验项一致：多版本、单启用、新上传默认启用最新
- 「含全部试验项」由绑定节点下当前试验项动态计算，不冗余存储

### 试验项单模版（不变）

维持现有 `RECORD_DATA`：`{ id, tree, test, file, configured, templates[] }`。

### 树节点标记

| 属性 | 节点 | 说明 |
|------|------|------|
| `sample: true` | 含型号子节点的节点 | 可上传组合模版 |
| `model: true` | 型号叶子 | 可上传组合模版 |
| 无标记 | 分类节点 | **不可上传**；选中时展示说明卡片 |

## 导出模版解析

### 继承链（仅运行时，无 UI 态）

```
resolveCombinedTemplate(modelId):
  1. bindType='model' AND bindTarget=modelId 且有启用文件 → 返回该记录
  2. 找 modelId 的上级 sample 节点，bindType='sample' 且有启用文件 → 返回该记录
  3. 否则 → null（走试验项拼接）
```

**不在继承链中**：分类层、试验项层。

### 按生成模式取模版

#### 单种样品所有试验生成一份文件

```
1. combined = resolveCombinedTemplate(型号)
2. IF combined → 使用该组合模版生成 1 个文件
3. ELSE → 动态拼接该型号下各试验项启用单模版
4. IF 拼接 AND 存在任意试验项缺单模版 → 阻断，提示：缺少「{试验项名}」的模版
5. IF 拼接 AND 试验项模版齐全 → 生成 1 个文件
```

#### 单个样品所有试验生成一份文件

- **模版解析**与「单种样品所有试验生成一份文件」相同（按型号 resolve / 拼接）
- **文件切分**按委托中单个样品实例（试样编号维度），每个样品实例 1 个文件

#### 单种样品单种试验生成一份文件

- 始终使用各试验项单模版，**忽略**组合模版
- 每个已完成试验项 → 各 1 个文件；缺模版 → `缺少「{试验项名}」的模版`

#### 单个样品单种试验生成一份文件

- 同「单种样品单种试验生成一份文件」，按样品实例 × 试验项切分

### 导出抽屉状态

| 状态 | 合并类两种模式 | 切分类两种模式 |
|------|--------------|--------------|
| 就绪 | 有组合模版，或试验项单模版齐全可拼接 | 对应该试验项有单模版 |
| 缺模版 | 无组合且拼接时缺任一试验项单模版 | 该试验项无单模版 |
| 试验未完成 | 不变 | 不变 |

抽屉**不展示**模版继承来源；仅按上述规则计算就绪/缺模版。

## 页面 UI

### 布局

```
.tpl-main
├── .tpl-toolbar
├── #combinedTemplatePanel    ← 组合模版卡片（分类/样品/型号/试验项节点规则见下）
├── .tpl-table-section
│   ├── section 标题 + 副标题
│   └── 统一表格（组合行 + 试验项行）
└── #infoBar
```

### 组合卡片 · 按选中节点

| 选中节点 | 卡片行为 |
|---------|---------|
| **分类节点** | **展示**说明卡片：分类层不支持上传组合模版，请在样品层或型号层配置；无上传/版本按钮 |
| **样品层** | 管理本节点组合模版；文件列 `xxx.docx` / `未上传` |
| **型号层** | 管理本节点组合模版；文件列 `xxx.docx` / `未上传`（不显示继承文案） |
| **试验项** | 折叠条只读：展示**本型号**在表格中对应组合行的文件状态（`xxx.docx` / `未上传`），无配置按钮 |

### 组合卡片 · 操作按钮

| 操作 | 说明 |
|------|------|
| **配置** | PageOffice 编辑本节点已上传的启用组合模版；`未上传` 时 disabled |
| **版本** | 上传、复制其他项、改名、删除、启用切换（与试验项版本弹窗一致） |
| **预览** | 原型 alert |
| **清除** | 清空本节点组合模版；不展示「恢复继承」，导出时自动回退上级 |

**不提供**：卡片级「复制」「恢复继承」「上传独立模版」。

### 统一表格

新增 **模版类型** 列；组合行与试验项行同表展示，**均参与筛选**。

| 模版类型 | 绑定层级 | 样品名称(型号) | 试验项 | 模板文件 | 操作 |
|---------|---------|--------------|--------|---------|------|
| 组合模版 | 样品/型号 | 绑定对象名 | 全部试验项 | `xxx.docx` / `未上传` | 配置·版本·预览·清除 |
| 试验项模版 | — | 型号名 | 试验项名 | `xxx.docx` / `未上传` | 配置·版本·预览·清除 |

**筛选栏**

| 筛选项 | 规则 |
|--------|------|
| 模版类型 | 全部 / 组合模版 / 试验项模版 |
| 是否已配置 | 是 = 有本行实际上传的启用文件；**依赖上级继承不算已配置** |
| 样品、样品分类、试验项、文件名 | 对两类行均生效 |

**Section 副标题**

> 用于「单种样品单种试验生成一份文件」「单个样品单种试验生成一份文件」；「单种样品所有试验生成一份文件」「单个样品所有试验生成一份文件」无本型号/上级样品组合模版时，按试验项单模版动态拼接。

**样品层选中**：表格按型号分组（分组头可点击跳转树节点）。

**交互**：点击表格组合行 → 选中对应树节点并刷新上方卡片。

### 左侧树

- 型号节点括号：保留 `(试验项已配/总数)`
- **不展示**组合模版继承/组合 badge
- 样品层、分类层不增加组合状态角标

### 版本弹窗

- `context: 'combined' | 'test-item'`
- 组合模版标题：`组合记录单模版 · {绑定对象}`
- 内含「复制其他项」（不在卡片上单独提供复制按钮）

### PageOffice

- 组合模版 `type='record-combined'`
- 字段面板展示绑定范围全部试验项占位

### 底部说明条

> 记录单模版支持 **样品层 / 型号层组合模版**（一份 Word 含全部试验项），以及各 **试验项单模版**。分类层不支持上传组合模版。
>
> - **「单种样品所有试验生成一份文件」「单个样品所有试验生成一份文件」**：优先使用本型号组合模版；若无则使用上级样品组合模版；若仍无则按试验项单模版动态拼接；拼接时缺任一试验项模版则报错。
> - **「单种样品单种试验生成一份文件」「单个样品单种试验生成一份文件」**：始终使用各试验项单模版，忽略组合模版。
>
> 导出切分规则由「业务流程配置 › 记录单设置」决定。同一模版可存多个版本，同时仅启用一个。

## 边界情况

| 场景 | 处理 |
|------|------|
| 型号未上传、样品已上传 | UI 型号行显示「未上传」；导出合并类模式自动用样品组合模版 |
| 型号版本上传 | 创建本层记录，`configured=true`，文件显示 `xxx.docx` |
| 型号清除 | 删除本层记录，UI 显示「未上传」；导出回退样品层 |
| 样品清除 | 下级型号 UI 仍「未上传」；导出回退试验项拼接 |
| 无样品层的型号（如 `glove`） | 仅型号层可上传；导出无组合则直接拼接 |
| 分类节点 | 卡片仅说明，表格列出子范围内所有组合行 + 试验项行 |
| 试验项增删 | 不自动作废已上传组合模版；生成时按当前试验项列表渲染 |

## 测试要点（原型）

1. 样品层 / 型号层上传组合模版，UI 仅显示 `xxx.docx` / `未上传`，无继承文案
2. 型号「未上传」、样品「已上传」：型号行筛选「未配置」命中；导出合并类模式仍成功（运行时取样品模版）
3. 合并类模式：无组合模版时拼接；缺任一试验项单模版 → 「缺少「xxx」的模版」
4. 切分类两种模式：忽略组合模版，仅校验试验项单模版
5. 分类节点：卡片展示说明、无上传按钮；表格正常列出子级组合行与试验项行
6. 筛选「模版类型」「是否已配置」对组合行、试验项行均生效
7. 说明条与 section 副标题使用完整模式名称，不出现「模式 1/2/3/4」
8. 版本弹窗内「复制其他项」可复制组合模版；卡片无独立复制按钮

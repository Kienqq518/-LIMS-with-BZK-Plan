**日期**: 2026-07-19（2026-07-19 晚 UI 迭代同步）

## 背景

现有记录单模版仅支持 **样品名称(型号) × 试验项** 单模版绑定；合并类导出依赖各试验项模版动态拼接。本次扩展 **样品层 / 型号层组合模版**（一份 Word 含该范围内全部试验项），与试验项单模版并存，导出时按生成模式自动选择来源。

**不在本次范围**：分类层上传组合模版、后端 API。

---

## 已确认决策摘要

| 议题 | 决策 |
|------|------|
| 绑定层级 | **样品层 + 型号层** 可上传；**分类层不上传** |
| 页面布局 | **上下分区**：组合模版表格 + 试验项模版表格（非统一表格） |
| 右侧数据范围 | 左侧选中节点的 **本层级及以下** 全部相关数据 |
| 导出分流 | 合并类模式用组合模版（导出时解析继承）；切分类模式始终用试验项单模版 |
| 继承链（仅导出时） | **型号层 > 样品层**（不含分类层） |
| 继承 UI | **不展示**；模版文件列仅 `xxx.docx` / `未上传` |
| 是否已配置 | 本节点实际上传了启用中文件 = 已配置；依赖上级继承 = **未配置** |

## 术语表

| 术语 | 含义 |
|------|------|
| **样品层** | 树中直接包含 ≥1 个 `model:true` 子节点的节点（`sample:true`），如 `DS实壁类塑料电缆导管_直管` |
| **型号层** | `model:true` 节点，如 `PVC-C` |
| **组合模版** | 绑定样品层或型号层，一份 Word 含该绑定范围内全部试验项占位 |
| **试验项单模版** | 现有 `RECORD_DATA` 行，一试验项一模版 |
| **动态拼接** | 无可用组合模版时，拉取各试验项启用模版拼接为一个 Word |

### 生成模式（UI 全文案）

| 模式 | UI 文案 |
|------|---------|
| 合并 · 按型号 | **单种样品所有试验生成一份文件** |
| 切分 · 按型号 | **单种样品单种试验生成一份文件** |
| 合并 · 按样品实例 | **单个样品所有试验生成一份文件** |
| 切分 · 按样品实例 | **单个样品单种试验生成一份文件** |

## 配置优先级

```
记录单设置（生成模式） > 记录单模版（组合 + 单试验项） > 导出抽屉（仅预览与执行）
```

## 数据模型

### 组合模版（`RECORD_COMBINED_DATA`）

```javascript
{
  id: 1,
  bindType: 'sample' | 'model',
  bindTarget: 'ds-s',
  bindLabel: 'DS实壁类塑料电缆导管_直管',
  file: '实壁导管_全套记录单.docx',
  configured: false,
  templates: [{ name: '...', time: '...', enabled: true, uploader: 'admin' }]
}
```

### 试验项单模版（不变）

维持现有 `RECORD_DATA`：`{ id, tree, test, file, configured, templates[] }`。

---

## 导出模版解析

### 继承链（仅运行时，无 UI 态）

```
resolveCombinedTemplate(modelId):
  1. bindType='model' AND bindTarget=modelId 且有启用文件 → 返回该记录
  2. 找 modelId 的上级 sample 节点，bindType='sample' 且有启用文件 → 返回该记录
  3. 否则 → null（走试验项拼接）
```

### 按生成模式取模版

- **单种样品所有试验 / 单个样品所有试验**：组合优先 → 继承 → 试验项拼接；拼接缺项报错
- **单种样品单种试验 / 单个样品单种试验**：始终试验项单模版，忽略组合模版

## 页面 UI

### 布局

```
.tpl-main
├── .tpl-toolbar（筛选）
├── #recordCombinedSectionHead + #combinedTemplatePanel   ← 组合记录单模版表格
├── #recordTableSectionHead + #dataTable                  ← 试验项模版表格
└── #infoBar
```

### 组合记录单模版表格

**列**：绑定层级 · 绑定对象 · 覆盖范围 · 模板文件 · 操作（**无「适用模式」**）

| 选中节点 | 行为 |
|---------|------|
| **分类层** | 汇总展示范围内全部样品层 + 型号层行；无可展示行时仅说明行 |
| **样品层** | 本样品层 1 行 + 其下全部型号层行 |
| **型号层** | 本型号 1 行 |
| **试验项** | **整区隐藏** |

- 多行排序与 **左侧树顺序** 一致（如 C → U → M → H）
- 绑定对象列 ~300px；操作列收紧至按钮宽度

**操作**：已上传 → 配置·版本·预览·清除；未上传 → 仅 **版本**（复制走版本弹窗「复制其他项」）

**复制弹窗（组合）**：表头与组合表一致 + 单选/序号；**无试验项列、无适用模式列**

### 试验项模版表格

**列**：☐ · 序号 · 样品名称(型号) · 样品分类 · 试验项 · 模板文件 · 操作

- **仅试验项单模版**，不含组合行
- 样品层选中：按型号分组
- 未上传行操作列 **仅「版本」**，列表不展示「复制」

### 筛选工具栏

| 筛选项 | 说明 |
|--------|------|
| 是否配置模板 | 是/否/全部 |
| 样品、试验项、文件名 | 模糊匹配 |

**已移除**：样品分类筛选、模版类型筛选（范围由左侧树决定）

### 左侧树

- 型号括号 `(已配/总数)`；试验项绿点；**无**组合继承 badge

### 底部说明条

合并类 / 切分类规则与完整模式名称，见 Story 同步稿 §10。

## 边界情况

| 场景 | 处理 |
|------|------|
| 型号未上传、样品已上传 | UI 型号「未上传」；导出合并类用样品组合模版 |
| 分类节点 | 组合表汇总子级；不可上传 |
| 试验项节点 | 隐藏组合区 |
| 无样品层的型号 | 仅型号层可上传；无组合则拼接 |

## 测试要点（原型）

1. 组合表无「适用模式」；试验项选中时组合区隐藏
2. 样品层：组合表 1 样品行 + 多型号行，顺序 CUMH
3. 分类层：组合表汇总全部子级行
4. 试验项表独立；未上传仅「版本」
5. 组合复制弹窗表头与组合表一致
6. 筛选无样品分类/模版类型

# 记录单公共模版与引用设计

**日期**: 2026-07-27  
**范围**: 模板管理 › 记录单模版  
**状态**: 已确认，原型更新中  
**对齐**: [`2026-07-27-report-public-template-ref-design.md`](2026-07-27-report-public-template-ref-design.md)、[`2026-07-19-record-combined-template-design.md`](2026-07-19-record-combined-template-design.md)

## 目标

记录单模版采用与报告模版一致的「业务 Tab + 公共库」模式：

```
记录单模版
├── Tab：记录单模版   （保留上下分区：组合 + 试验项）
└── Tab：公共模版     （组合记录单模版 | 试验项模版）
```

## 已确认决策

| 议题 | 决策 |
|------|------|
| 引用入口 | 另做「编辑」弹窗（上传 / 复制 / 引用） |
| 公共关联绑定 | **不需要**关联绑定列；业务侧在记录单模版 Tab 选择引用即可 |
| 引用语义 | **活引用**（与报告一致） |
| 记录单模版布局 | **保留**上下分区 |

## 公共模版 Tab

### 列表

列：序号 · 模版内容样式 · 模版文件 · 操作  

操作：编辑 | 版本 | 配置 | 预览 | 删除  

筛选：模版内容样式（全部 / 组合记录单模版 / 试验项模版）、模版文件名  

无「关联绑定」筛选项与列。

### 数据 `RECORD_PUBLIC_DATA`

```javascript
{
  id: 1,
  contentStyle: '组合记录单模版' | '试验项模版',
  templateName: '电网物资通用组合记录单',
  file: '电网物资通用组合记录单.docx',
  ext: '.docx',
  cat: 'dlwz',
  templates: [{ name, time, enabled, uploader }]
}
```

### 新增/编辑弹窗

**新增**
- 模版内容样式（必填）
- 模板文件（上传 / 复制）→ 写入首个启用版本
- 模版名称（可随上传回显）

**编辑（仅元数据）**
- 可改：模版内容样式、模版名称
- 当前启用文件**只读**展示；上传/复制/启用/改文件名一律走操作列「版本」
- 模版名称与启用版本文件名**解耦**
- 若已被记录单模版引用：**禁止更改内容样式**（需先解除引用）

无绑定维度字段。

## 记录单模版 Tab

保留现有：

- 上：组合记录单模版表
- 下：试验项模版表
- 左树、筛选、版本弹窗（本地多版）

### 新增「编辑」弹窗

对组合行 / 试验项行均可打开，配置正文来源：

| 模式 | 行为 |
|------|------|
| 上传 | 选文件，写入/追加本地版本 |
| 复制 | 从其他同类业务行复制 |
| 引用 | 下拉选对应类型公共模版；文件名只读 |

引用下拉过滤：

- 组合行 → `contentStyle === '组合记录单模版'`
- 试验项行 → `contentStyle === '试验项模版'`
- 当前大类 `cat`

### 数据增量

`RECORD_DATA` / `RECORD_COMBINED_DATA` 增加可选 `refPublicId`。

- 有 `refPublicId`：活引用；`file` 跟随公共启用版本；本地 `templates` 可空
- 「版本」：引用行打开公共模版版本；本地行打开原版本弹窗
- 列表文件列：引用显示「引用」标记；不显示「启用中」

### 编辑策略（对齐报告）

- 本地：可改切为引用；本地文件以「版本」为主
- 引用：可改公共目标；可切回上传/复制转为本地

## 导出

`resolveCombinedTemplate` / 试验项 `file` 解析时，若存在 `refPublicId`，取对应 `RECORD_PUBLIC_DATA` 当前启用文件（活引用）。

## 编辑 vs 版本职责

| 入口 | 可改 |
|------|------|
| 编辑弹窗 | `contentStyle`、`templateName` |
| 版本弹窗 | `templates[]` 上传/复制/启用/改文件名/删除；同步 `file` |

禁止：编辑弹窗改写启用版文件名或覆盖文件实体。

## 不在本次范围

- 公共模版按样品/试验项自动推荐（无绑定列）
- 报告侧公共模版编辑/版本职责收口（同类问题，另案处理）

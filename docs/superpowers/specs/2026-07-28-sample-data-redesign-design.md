# 样品数据页整改设计（定稿）

## 范围

仅改「样品数据」主数据页（大类卡片 → 大类详情左右分栏）。委托/试验检测/制备流程页本期不改，但约定契约如下。

## 结构

- 大类卡片入口保留
- 左树参考标准→样品层级；**仅样品叶节点可选**；中间节点只展开
- 同名样品在不同标准下为不同主数据（后台编码不同，前端不展示编码）
- 右侧 Tab：基本信息 | 型号 | 试验
- 移除「导出」；保留「一键同步样品试验数据」（tooltip：将 LIMS 样品数据结构同步至直连数采系统）

## 数据关系

- **试验 Tab** = 样品默认试验模板（结构唯一真相）
- **型号 Tab** = 型号档案 +「配置试验」关联默认试验并快照取值
- 型号可覆盖取值类字段；**永不回写**默认
- 默认改取值：**不覆盖**已关联型号
- 默认改结构：**强同步**到已关联型号
- 默认「新增一条试验」：弹窗选择是否同步到全部/部分型号/不同步
- 无型号→首次加型号：默认侧保留模板值，同时复制到型号

## 是否制样 / 制备流程

- 「是否制样」仅在**试验项级**（默认试验 + 型号覆盖态）
- 业务流转时：看**委托登记时该样品（型号）勾选要做的试验**（不是配置里全部试验）
  - 所选试验中**任一**有效「是否制样=是」→ 走样品制备
  - 全部为否 → 不走样品制备

## 字段要点

- 基本信息：样品分类、名称、排序、再检周期、单位、描述、图片、附件；去掉编码与是否制样
- **再检周期**（原「再检期限」）：下拉（文本/数值）+ 文本框组合
  - 选「数值」：输入框仅允许数字；合格证再检日期 = 检测日期 + 再检周期（月）
  - 选「文本」：自由文本，内容直接加载到合格证（部分样品无固定再检日期，仅展示文字）
  - 型号侧同样使用该组合组件
- 试验级：增加试样类别代码、试样色号（字典）、是否制样、试样数量（制样=是时）、检测类别（字典 `lims_detect_category`，标签受委托信息配置中对应字段名称控制）、标准要求多段拼接器；去掉试验编码、检测周期
- 检测项：去掉编码与项级标准要求；增加是否必填、隐藏（隐藏则必填锁定为否）；类型=下拉时展示可选项
- 默认值（含标称值）**永远非必填**
- 型号列表不含是否制样、不含标准要求；「关联」改为「配置试验」

## 编码

试验编码、检测项编码仅后台调度用，前端不可见、不可编辑。

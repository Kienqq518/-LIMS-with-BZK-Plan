## 1. 目标与非目标

### 1.1 目标

1. **样品标签**、**合格证**版式可配置：纸张布局、品牌区、字段槽位（勾选 / 排序 / 改显示名）。
2. **按样品大类隔离配置**；大类内模版绑定一个或多个**样品主数据叶节点**（如「绝缘操作杆」，不到规格型号）；打印时按样品解析模版。
3. **样品管理**新增「**合格打印**」：按样品一行展示，**仅合格样品**；查询列见 §7。
4. **试验管理 → 标签打印**保持现状入口能力（样品标签 + 合格证都保留），不拆除。
5. 门禁：**报告签发及后续** + **判定合格**；不合格禁止打印合格证。
6. 检验人员：最多 N 人（参数可配，默认 2）；首次必选，之后记忆。
7. 打印方式维持浏览器 `window.print()`（不对接标签机指令）。
8. 证面**不包含**「合格证编号」字段。

### 1.2 非目标（本期）

- Word/PageOffice 作为合格证/标签主编辑器
- 标签打印机 SDK / TSPL / ZPL
- 多语言证面
- 改变短链验真协议本身（仅消费短链模块）
- 把合格证入口从「标签打印」迁走（明确保留双入口）

## 2. 已确认决策

| 议题 | 决策 |
|------|------|
| 配置隔离 | 每个**样品大类**一套配置空间 |
| 绑定粒度 | **样品叶节点**（如绝缘操作杆）；不绑规格型号 |
| 绑定数量 | 一个模版可勾选多个样品；同大类同类型下一样品仅能绑一个启用模版 |
| 配置形态 | **布局预设 + 结构化版式编辑器**（纸张/布局、品牌区、字段池） |
| 样品标签默认字段 | 样品编号、样品名称、型号规格、收样日期、送检单位、检测状态 |
| 样品标签扫码 | 实验室内部流转；扫码展示 = 标签左侧已配置字段 |
| 纸张/打印 | 浏览器打印；不做标签机协议 |
| 标签打印菜单 | **不动**：仍同时提供样品标签、合格证 |
| 合格打印菜单 | 样品管理**新增**；仅合格样品列表 + 打证 |
| 单位名 | 可配；默认 = **检测机构名称（B1）**；模版可改，打印前可再编辑本次 |
| Logo | 可开关；默认系统 Logo；可自定义上传 |
| 检验人员 | 最多 2（上限参数化）；首次必选；之后记忆 |
| 门禁 | 报告签发及后续 **且** 判定合格；不合格禁止 |
| 合格证编号 | **证面不要**此字段 |

### 2.1 术语：`inspectors`（检验人员 / 检查员）

打印合格证时选择的人员姓名（弹窗最多 N 人），写入证面对应行。样例证面显示名为「检查员」；字段池 id 仍为 `inspectors`，默认显示名按布局预设给出（可改）。样品标签字段池不含此项。

## 3. 样例解析与配置形态

### 3.1 样例文档结论

文档主体是「工器具 × 合格证材质/样式/尺寸/安装方式/赋码打印方式」对照表。证面样式列实际只有 **两种可复用图样**：

| 样式图 | 材质 | 尺寸 | 安装 | 典型工器具 |
|--------|------|------|------|------------|
| [cert-style-1](assets/label-cert-styles/cert-style-1-adhesive.png) | 不粘胶纸 | **6.5cm × 3cm** | 粘贴 | 安全帽、绝缘杆、绝缘手套等多数 |
| [cert-style-2](assets/label-cert-styles/cert-style-2-pvc.jpg) | PVC | **5cm × 2.5cm** | 悬挂（圆孔） | 安全带、安全绳、缓冲器、绝缘托瓶架等 |

同一样式被大量工器具复用 → 与「一模版绑定多样品」完全吻合：例如「PVC 悬挂模版」一次勾选安全带、安全绳、缓冲器…

### 3.2 两种合格证骨架（对应图1 / 图2）

**预设 `cert_style_1`（不粘胶纸 · 字段表格式）**

```
┌─────────────────────────────────────┐
│  [Logo?]  检测机构名称               │
│           检验合格证                 │
│─────────────────────────────────────│
│ 试样名称：___________                │
│ 规格型号：___________                │
│ 试样编号：___________                │
│ 检查员：  ___________                │
│ 本次检测日期：_______                │
│ 下次检测日期：_______                │
│         （背景可有浅色「格」底纹）      │
└─────────────────────────────────────┘
纸张默认：65mm × 30mm
```

- 品牌区：机构名 + 标题「检验合格证」+ 可选 Logo  
- 字段区：纵向 label+值，顺序可配  
- 二维码：样例静态图未强调中置码；实现上**支持右侧或角部小码**（短链验真），由预设内 `qr.placement` 控制；可关  
- 适合字段较多的粘贴证

**预设 `cert_style_2`（PVC · 大字中置码）**

```
┌─────────────────────────────────────┐ ○←悬挂孔
│         检测机构名称                 │
│         检验合格证                   │
│                                     │
│     合  [QR码]  格                   │
│    扫一扫     查信息                  │
│                                     │
│ 检测有效期：____年__月__日 止         │
│ 无法扫码视为过期（提示文案可配）        │
└─────────────────────────────────────┘
纸张默认：50mm × 25mm
```

- 品牌区：机构名 + 标题  
- 中心：合格示意字 + **必选中置 QR**（验真短链）  
- 主数据字段极简：默认突出 `validUntil`（检测有效期止）＝再检/有效期日期  
- 底部警示文案可配  
- 适合悬挂小牌、扫码为主

### 3.3 为什么用「布局预设 + 结构化编辑」

| 观察 | 设计含义 |
|------|----------|
| 仅 2 种证面骨架、被数十种工器具复用 | 预设固化骨架；样品绑定解决「谁用哪套」 |
| 尺寸/材质/安装方式随样式走 | 纸张默认跟预设；材质/安装作模版备注即可（不进打印渲染） |
| 字段集在两种样式间差异大 | 字段池勾选 + 排序 + 改显示名；预设可带「推荐字段包」 |
| 品牌强依赖机构名 | 品牌区独立配置，默认 B1 检测机构名 |
| 小尺寸贴纸 | 不用 Word 主路径 |

### 3.4 图3 / 图4 约定

上传的《安全工器具合格证样式.docx》**未包含**单独标注的图3、图4。定稿约定：

| 预设 | 来源约定 | 说明 |
|------|----------|------|
| `cert_style_3` | **现网原型左文右码**（`cert-print-*.html`） | 作为第三种合格证骨架保留，兼容当前演示 |
| `label_style_1` | **你方描述的样品标签**（左字段 + 右二维码） | 扫码展示左侧配置字段；默认字段见 §4.3 |

若图3/图4 另有视觉稿，可再替换预设示意，不改变配置模型。

## 4. 信息架构

### 4.1 配置入口

系统配置侧新增：**标签与合格证模版**。

```
标签与合格证模版
  ├─ 顶部：样品大类（电力物资类 / 安全工器具类 / …）
  └─ 左：样品标签 | 合格证
       └─ 右：模版列表（名称、布局预设、纸张、已绑样品数、默认标记、启用、操作）
            └─ 编辑：版式编辑器 + 样品多选绑定
```

### 4.2 样品绑定

- 对象：当前大类样品树**叶节点**（与样品数据页一致）。
- 一模版多选样品；冲突校验：同大类同类型下一样品不可属于两个启用模版。
- 未命中绑定 → 回退该大类该类型的**默认模版**；无默认则阻断提示。

### 4.3 版式编辑器

#### A. 纸张与布局

| 项 | 说明 |
|----|------|
| 布局预设 | 合格证：`cert_style_1` / `cert_style_2` / `cert_style_3`；标签：`label_style_1` |
| 纸张 mm | 随预设默认，可微调 |
| 字号档 / 边距 | 紧凑 / 标准 |
| 备注（可选） | 材质、安装方式、赋码打印方式（喷墨/激光）— 仅说明，不渲染 |

#### B. 品牌区

| 项 | 说明 |
|----|------|
| 单位名称 | 默认检测机构名（B1）；可编辑 |
| 标题 | 样式1/2 默认「检验合格证」；样式3 默认「合 格 证」 |
| Logo | `system` / `custom` / `hidden` |
| 底纹/警示文案 | 样式1 可选「格」底纹开关；样式2 底部警示默认「无法扫码视为过期」 |

#### C. 字段槽位

字段池勾选、拖拽排序、改显示名。

**合格证字段池**

| 字段 ID | 建议默认显示名 | 说明 |
|---------|----------------|------|
| sampleName | 试样名称 | |
| specModel | 规格型号 | |
| specimenNo | 试样编号 | |
| inspectors | 检查员 | 打印时选择；样式2 可默认不勾 |
| inspectDate | 本次检测日期 | |
| reinspectDate | 下次检测日期 | 主数据再检周期：数值→日期，文本→原文 |
| validUntil | 检测有效期 | 样式2 主字段；取值同再检/有效期止 |
| qrCode | 二维码 | 验真短链；样式2 强制启用 |

**不含**：合格证编号。

**样式推荐字段包（新建模版时预勾）**

| 预设 | 预勾字段 |
|------|----------|
| `cert_style_1` | sampleName, specModel, specimenNo, inspectors, inspectDate, reinspectDate；（qr 可选） |
| `cert_style_2` | validUntil, qrCode（中置） |
| `cert_style_3` | specimenNo, sampleName, specModel, inspectDate, reinspectDate, inspectors, qrCode |

**样品标签字段池**

| 字段 ID | 默认显示名 | 默认勾选 |
|---------|------------|----------|
| sampleNo | 样品编号 | ✓ |
| sampleName | 样品名称 | ✓ |
| specModel | 型号规格 | ✓ |
| receiveDate | 收样日期 | ✓ |
| clientName | 送检单位 | ✓ |
| detectStatus | 检测状态 | ✓ |
| qrCode | 二维码 | ✓（内部流转码） |

### 4.4 运行参数

| 参数键 | 名称 | 默认 |
|--------|------|------|
| `cert.inspector.max` | 合格证检验人员上限 | `2` |
| `cert.shortlink.days` | 短链有效期(天) | `365`（已有，需接线） |
| `cert.shortlink.base` | 短链 Base URL | 环境配置 |

## 5. 数据模型

```javascript
LABEL_CERT_CONFIG[catKey] = {
  sample_label: { templates: Template[], defaultTemplateId },
  certificate:  { templates: Template[], defaultTemplateId }
}

Template = {
  id, name, enabled, updatedAt,
  layoutPreset: 'cert_style_1' | 'cert_style_2' | 'cert_style_3' | 'label_style_1',
  paper: { wMm, hMm },
  style: { fontScale, marginMm },
  brand: {
    orgName, title,
    logoMode: 'system' | 'custom' | 'hidden',
    logoUrl,
    showWatermarkGe: boolean,     // 样式1
    footerWarning: string | null  // 样式2
  },
  fields: [{ id, label, visible }],  // 顺序=数组序
  qr: {
    enabled, sizePx,
    payloadType: 'sample_flow' | 'cert_shortlink',
    placement: 'right' | 'corner' | 'center' | 'none'
  },
  meta: { material, mount, printMethod }, // 备注
  bindSampleIds: ['rod', 'belt976', ...]
}
```

### 5.1 解析

```
resolveTemplate(catKey, type, sampleMasterId):
  enabled = templates where enabled
  hit = enabled.find(t => t.bindSampleIds includes sampleMasterId)
  return hit || defaultTemplate || null
```

## 7. 双入口：标签打印 + 合格打印

### 7.1 试验管理 · 标签打印（保持）

- 继续提供「样品标签」「合格证」单打/批打。
- 渲染改为模版驱动；门禁升级为：合格证需 **签发后 + 判定合格**。
- 不合格样品：不展示合格证操作 / 不可勾选打证。

### 7.2 样品管理 · 合格打印（新增）

菜单：`样品管理` → **合格打印**。

**列表粒度**：样品实例一行。  
**数据范围**：仅**已判定合格**，且委托处于报告签发及后续。

**列 / 查询**

| 列 |
|----|
| 样品名称 |
| 样品编号 |
| 委托编号 |
| 合同编号 |
| 委托单位 |
| 委送样时间 |
| 客户要求完成时间 |
| 操作（打印合格证；支持多选批量） |

流程：勾选 → 检验人员（首次必选/其后记忆，≤N）→ `resolveTemplate(certificate)` → 预览（单位名可本次编辑）→ `window.print()` → 短链签发/复用。

---

## 8. 门禁（硬规则）

打印合格证须同时：

1. 委托状态 ∈ 报告签发及后续；  
2. 该样品判定**合格**；  

不合格：列表不可见（合格打印）或操作禁用（标签打印），接口层拒绝。  
短链回退作废规则不变。

## 1. 目标与非目标

### 1.1 目标

1. **样品标签**、**合格证**版式由用户**自由设计**：先定纸张宽高，再摆分类元素完成布局，再单独调整每个元素内容与样式。
2. **按样品大类隔离配置**；大类内模版绑定一个或多个**样品主数据叶节点**（如「绝缘操作杆」，不到规格型号）；打印时按样品解析模版。
3. **样品管理**新增「**合格打印**」：按样品一行展示，**仅合格样品**；查询列见 §7。
4. **试验管理 → 标签打印**保持现状入口能力（样品标签 + 合格证都保留），不拆除。
5. 门禁：**报告签发及后续** + **判定合格**；不合格禁止打印合格证。
6. 检验人员：最多 N 人（参数可配，默认 2）；首次必选，之后记忆。
7. 打印方式维持浏览器 `window.print()`（不对接标签机指令）。
8. 证面**不包含**「合格证编号」字段。

### 1.2 非目标（本期）

- Word/PageOffice 作为合格证/标签主编辑器
- 标签打印机 SDK / TSPL / ZPL
- 多语言证面
- 改变短链验真协议本身（仅消费短链模块）
- 把合格证入口从「标签打印」迁走（明确保留双入口）
- **布局预设 / 双模式**（预设模式 + 自由模式）— 明确不做；仅自由设计一条路径
- 字段流式容器 / 自动叠放组（一期全部绝对定位；用对齐与等距分布补齐排版效率）

## 2. 已确认决策

| 议题 | 决策 |
|------|------|
| 配置隔离 | 每个**样品大类**一套配置空间 |
| 绑定粒度 | **样品叶节点**（如绝缘操作杆）；不绑规格型号 |
| 绑定数量 | 一个模版可勾选多个样品；同大类同类型下一样品仅能绑一个启用模版 |
| 配置形态 | **仅自由设计**：纸张画布 + 分类元件库 + 同画布「布局 / 内容」双面板 |
| 新建方式 | **空白 + 纸张尺寸快捷**；或 **复制已有模版** 再改（见 §4.3） |
| 起始样板 | **不提供**系统布局预设/一键骨架；历史 `cert_style_*` / `label_style_1` 仅作迁移展开参考 |
| 字段唯一性 | 同一业务 `fieldId` 在模版内**最多 1 个**字段行元素 |
| 品牌唯一性 | `单位名称` / `标题` / `Logo` **各最多 1 个** |
| 二维码 | 每模版**最多 1 个**；`payloadType` 由模版类型锁定（证=短链，标签=流转） |
| 水印 / 检测章 | **可拖元素**（可多枚）；支持层级快捷：置于底层 / 置于顶层 |
| 编辑器交互 | **同画布双面板**随时切换布局/内容，无强制向导步骤 |
| 样品标签建议字段 | 样品编号、样品名称、型号规格、收样日期、送检单位、检测状态（+ 流转二维码） |
| 样品标签扫码 | 实验室内部流转；扫码展示 = 模版上已配置的业务字段行 |
| 纸张/打印 | 浏览器打印；不做标签机协议 |
| 标签打印菜单 | **不动**：仍同时提供样品标签、合格证 |
| 合格打印菜单 | 样品管理**新增**；仅合格样品列表 + 打证 |
| 单位名 | 添加「单位名称」元素时默认 = **检测机构名称（B1）**；可改 |
| Logo | 元素内容：`system` / `custom` / `hidden`（或删除元素） |
| 检验人员 | 最多 2（上限参数化）；首次必选；之后记忆 |
| 门禁 | 报告签发及后续 **且** 判定合格；不合格禁止 |
| 合格证编号 | **证面不要**此字段（元件库不提供） |

### 2.1 术语：`inspectors`（检验人员 / 检查员）

打印合格证时选择的人员姓名（弹窗最多 N 人），写入证面对应字段行。样例证面显示名可为「检查员」；字段池 id 仍为 `inspectors`，显示名在元素内容面板可改。样品标签字段池不含此项。

## 3. 样例解析与配置形态

### 3.1 样例文档结论

文档主体是「工器具 × 合格证材质/样式/尺寸/安装方式/赋码打印方式」对照表。证面视觉上常见两类：

| 参考图 | 材质 | 尺寸 | 安装 | 典型工器具 |
|--------|------|------|------|------------|
| [cert-style-1](assets/label-cert-styles/cert-style-1-adhesive.png) | 不粘胶纸 | **6.5cm × 3cm** | 粘贴 | 安全帽、绝缘杆、绝缘手套等多数 |
| [cert-style-2](assets/label-cert-styles/cert-style-2-pvc.jpg) | PVC | **5cm × 2.5cm** | 悬挂（圆孔） | 安全带、安全绳、缓冲器、绝缘托瓶架等 |

同款版式被大量工器具复用 → 仍用「一模版绑定多样品」解决；版式本身由用户在画布上自由搭，或从已配置好的模版**复制**后再改。

### 3.2 为什么改为「仅自由设计」

| 观察 | 设计含义 |
|------|----------|
| 客户要自行设计**包括布局** | 不再用系统骨架锁死区域；布局真相 = `elements[]` 坐标 |
| 常见尺寸仍有限 | 新建提供**纸张尺寸快捷**，不提供布局预设 |
| 已有好模版想微调 | 支持**复制已有模版**（深拷贝版式）；结果一律为个性化模版 |
| 字段/品牌/码/章诉求不同 | 分类元件库投放；布局与内容分面板编辑 |
| 小尺寸贴纸 | 毫米画布 + 浏览器打印；不用 Word 主路径 |

### 3.3 参考版式（非系统预设）

下列仅作实施/迁移时的**视觉参考**与纸张快捷来源，**不是**可选的 `layoutPreset`：

| 参考 | 纸张 | 典型元素组合 |
|------|------|----------------|
| 不粘胶字段表 | 65×30 / 65×45 mm | 单位名、标题、Logo、多条字段行、可选 QR、可选文本水印/章 |
| PVC 悬挂中置码 | 50×25 mm | 单位名、标题、中置 QR、有效期字段、警示静态文本、悬挂孔 |
| 左文右码 | 90×50 mm | 左侧字段行 + 右侧 QR |
| 样品标签 | 60×40 mm | 左侧字段行 + 右侧流转 QR |

## 4. 信息架构

### 4.1 配置入口

挂在 **检测管理 → 模板管理** 落地页第四张卡片：**标签与合格证模版**（`template-config.html?type=labelCert`）。

```
模板管理
  ├─ 报告模版 / 记录单模版 / 单据模版 / 标签与合格证模版
  └─ 标签与合格证模版
       ├─ 顶部：样品大类横向 Tab（与报告/记录单一致）
       └─ 左：合格证 | 样品标签
            └─ 右：
                 ├─ 默认模版（固定区，1 条：可编辑版式，不可删/停用/绑样品）
                 └─ 个性化模版列表（绑样品覆盖；可启停/删除；停用回退默认）
```

### 4.2 默认与个性化 · 样品绑定

- **默认模版**：每大类 × 每类型恰好 1 个；永启用；不绑定样品；可编辑版式；不可删除、不可停用、不可改为个性化。
- **个性化模版**：覆盖指定样品；**保存/启用前必须绑定 ≥1 个样品叶节点**；可启停、可删除。
- 对象：当前大类样品树**叶节点**（与样品数据页一致）。
- 冲突校验：同大类同类型下一样品不可属于两个**启用中的个性化**模版。
- 解析：`启用个性化命中绑定` → 否则 → **默认模版**；无默认则阻断（系统保证必有默认）。

### 4.3 新建模版

两种入口，**均无系统布局预设**：

#### A. 空白创建

1. 填写模版名称  
2. 选择纸张尺寸快捷，或自定义 `wMm × hMm`  
3. 进入编辑器：`elements: []` 的空白画布  

**纸张尺寸快捷（可扩展）**

| 快捷名 | mm | 说明 |
|--------|-----|------|
| 粘贴证（紧凑） | 65×30 | 对齐样例不粘胶 |
| 粘贴证 | 65×45 | 字段较多时 |
| 悬挂牌 | 50×25 | PVC 小牌 |
| 左文右码 | 90×50 | 现网比例 |
| 样品标签 | 60×40 | 流转标签 |
| 自定义 | 手输宽高 | 校验合理范围（如 20–200 mm） |

空白创建的新模版进入**个性化**列表（须绑样品后启用）。默认模版不通过「新建」产生，由系统按大类×类型保证存在；其版式同样用自由设计编辑器维护。

#### B. 从已有模版复制

1. 选择源模版：仅 **当前大类 × 当前类型** 列表（含默认与个性化）  
2. 生成新 id、默认名称「{源名称} 副本」（可改）  
3. **深拷贝** `paper`、`elements`（含布局坐标与内容 props）、`meta`  
4. **`bindSampleIds` 清空**；`enabled` 默认 false 或按产品约定（启用前须完成样品绑定）  
5. **结果一律为个性化模版**（即使源是默认模版，也不可「另存为第二个默认」）  
6. 进入编辑器继续改  

跨大类、跨类型（合格证 ↔ 样品标签）禁止复制，避免字段池与二维码类型错乱。

### 4.4 自由设计编辑器

#### 整体结构

```
┌──────────────┬──────────────────────────┬────────────────────┐
│ 分类元件库   │  纸张画布（mm）            │ 属性面板           │
│ · 品牌标识   │  标尺 / 网格吸附           │  [布局] [内容]     │
│ · 业务字段   │  拖拽 / 缩放 / 多选对齐    │  随选中元素切换    │
│ · 码与章     │  等距分布 / 锁定           │                    │
│ · 装饰辅助   │                          │  未选中：纸张/备注  │
└──────────────┴──────────────────────────┴────────────────────┘
```

- **同画布双面板**：布局 / 内容 Tab 随时切换，保留选中态；无强制「先完成布局再进内容」向导。  
- **工作顺序（引导，非强制）**：定纸张 → 从元件库投放并摆布局 → 再逐个调内容与样式。  
- 画布与打印预览可用样例数据灌值；打印渲染唯一路径读 `paper + elements[]`。

#### 布局面板（几何）

| 能力 | 说明 |
|------|------|
| 位置尺寸 | `xMm, yMm, wMm, hMm`；网格吸附（建议 0.5 / 1 mm） |
| 对齐 | 相对纸张或相对多选：左/右/顶/底/水平垂直居中 |
| 分布 | 多选时水平/垂直等距 |
| 层级 | 上移一层 / 下移一层；**水印、检测章**另提供 **置于底层 / 置于顶层** |
| 锁定 | `locked` 防误拖 |
| 删除 | 删除后，对应唯一性占用释放（字段可重新从库添加） |

#### 内容面板（按元素类型）

见 §4.5 各元素 `props`。未选中元素时编辑：模版名称、纸张宽高/边框、`meta` 备注（材质、安装、赋码打印方式 — 仅说明，不渲染）。

#### 布局效率

一期不做流式容器；字段多时依赖多选对齐与等距分布。元件不可超出纸张（保存时校验或吸附裁切策略：建议保存拦截并高亮越界项）。

### 4.5 元件分类与唯一性

| 分类 | type | 唯一性 | 布局要点 | 内容要点 |
|------|------|--------|----------|----------|
| 品牌标识 | `orgName` | 最多 1 | 位置尺寸 | `text`（默认 B1 机构名）、字号/颜色/对齐 |
| 品牌标识 | `title` | 最多 1 | 位置尺寸 | `text`（如「检验合格证」）、字号/颜色/对齐 |
| 品牌标识 | `logo` | 最多 1 | 位置尺寸 | `source`: system / custom / hidden；`url` |
| 业务字段 | `fieldRow` | 同一 `fieldId` 最多 1 | 位置尺寸 | `fieldId`、显示名 `label`、`showLabel`、值对齐、下划线、字号/颜色 |
| 码与章 | `qr` | 最多 1 | 位置尺寸 | 尺寸；`payloadType` **只读派生**（见下） |
| 码与章 | `seal` | 可多个 | 位置尺寸、旋转 | system / custom 章图、透明度；层级快捷 |
| 码与章 | `watermarkText` | 可多个 | 位置尺寸、旋转 | 文案、颜色、透明度、是否平铺；层级快捷 |
| 装饰辅助 | `staticText` | 可多个 | 位置尺寸 | 文案、字号/颜色/对齐（如警示语） |
| 装饰辅助 | `line` | 可多个 | 位置长短 | 粗细、颜色、实线/虚线 |
| 装饰辅助 | `hangHole` | 可多个 | 位置、孔径 | 无业务内容（仅几何，供悬挂牌） |

## 5. 数据模型

```javascript
LABEL_CERT_CONFIG[catKey] = {
  sample_label: { templates: Template[], defaultTemplateId },
  certificate:  { templates: Template[], defaultTemplateId }
}

Template = {
  id, name, enabled, updatedAt,
  paper: {
    wMm, hMm,
    border: { enabled, color, widthPx }
  },
  meta: { material, mount, printMethod },  // 备注，不渲染
  bindSampleIds: [],                       // 默认模版恒为 []
  elements: Element[]                      // 版式唯一真相
}

Element = {
  id: string,
  category: 'brand' | 'field' | 'code' | 'decor',
  type: 'orgName' | 'title' | 'logo'
      | 'fieldRow' | 'qr' | 'seal' | 'watermarkText'
      | 'staticText' | 'line' | 'hangHole',
  xMm, yMm, wMm, hMm,
  zIndex: number,
  locked: boolean,
  rotationDeg?: number,   // 主要用于 seal / watermarkText
  props: {
    // orgName | title | staticText
    text?, fontSize?, color?, align?,
    // logo | seal
    source?: 'system' | 'custom' | 'hidden',
    url?, opacity?,
    // fieldRow
    fieldId?, label?, showLabel?, valueAlign?,
    underline?: 'none' | 'solid' | 'dotted' | 'dashed',
    // qr — payloadType 由模版类型派生，可冗余存储便于渲染
    payloadType?: 'sample_flow' | 'cert_shortlink',
    // watermarkText
    tile?: boolean
  }
}
```

**已废弃作为主路径的字段**（迁移后不再读写为真相）：  
`layoutPreset`、`fields[]`、`brand` 大对象、`qr.placement` / 全局 `qr`、全局水印九宫配置。

### 5.1 解析

```
resolveTemplate(catKey, type, sampleMasterId):
  enabled = templates where enabled
  hit = enabled.find(t => t.bindSampleIds includes sampleMasterId)
  return hit || defaultTemplate || null
```

### 5.2 渲染

```
renderSheet(tpl, data):
  按 paper 建立画布
  elements 按 zIndex 升序绘制
  fieldRow / 业务相关：从 data 按 fieldId 取值
  qr：按 payloadType 生成载荷并绘制
```

打印入口（标签打印 / 合格打印）仍只依赖 `resolveTemplate` → `renderSheet`，不感知编辑器 UI。

### 5.3 校验（保存 / 启用）

- 纸张宽高在允许范围；元素框不越界  
- 唯一性：`orgName` / `title` / `logo` / `qr` 各 ≤1；同一 `fieldId` 的 `fieldRow` ≤1  
- 个性化：启用前 `bindSampleIds.length ≥ 1`；样品冲突规则同 §4.2  
- 无「必须有二维码」硬拦（可警告）；证面不得出现合格证编号

## 6. 样品标签扫码

- 载荷：内部流转地址（非合格证验真短链）。  
- 扫码页字段集 = 模版 `elements` 中 `type === 'fieldRow'` 的字段（建议按 `yMm` 再 `xMm` 排序）。  
- 用途：实验室内部流转识别。

## 7. 双入口：标签打印 + 合格打印

### 7.1 试验管理 · 标签打印（保持）

- 继续提供「样品标签」「合格证」单打/批打。  
- 渲染改为模版驱动（自由 `elements`）；门禁：合格证需 **签发后 + 判定合格**。  
- 不合格样品：不展示合格证操作 / 不可勾选打证。

## 8. 门禁（硬规则）

打印合格证须同时：

1. 委托状态 ∈ 报告签发及后续；  
2. 该样品判定**合格**；  

不合格：列表不可见（合格打印）或操作禁用（标签打印），接口层拒绝。  
短链回退作废规则不变。

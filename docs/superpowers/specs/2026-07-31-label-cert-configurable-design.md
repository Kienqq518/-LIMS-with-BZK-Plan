## 1. 目标与非目标

### 1.1 目标

1. **样品标签**、**合格证**版式可配置：纸张布局、品牌区、字段槽位（勾选 / 排序 / 改显示名）。
2. **按样品大类隔离配置**；大类内模版绑定一个或多个**样品主数据叶节点**；打印时按样品解析模版。
3. 合格证打印迁入样品管理新页面「**合格打印**」，列表按**样品实例一条一行**，且**仅展示已判定合格**的样品。
4. 门禁：**报告签发及后续** + **判定合格**；不合格禁止打印合格证。
5. 检验人员：最多 N 人（参数可配，默认 2）；首次必选，之后记忆。
6. 打印方式维持浏览器 `window.print()`（不对接标签机指令）。

### 1.2 非目标（本期）

- Word/PageOffice 作为合格证/标签主编辑器（见 §3 形态决策）
- 标签打印机 SDK / TSPL / ZPL
- 多语言证面
- 改变短链验真协议本身（仅消费短链模块）

## 2. 已确认决策

| 议题 | 决策 |
|------|------|
| 配置隔离 | 每个**样品大类**一套配置空间 |
| 模版绑定 | 大类下模版绑定**样品**（可多选）；打印按样品命中模版 |
| 配置形态 | **布局预设 + 结构化版式编辑器**（纸张/布局、品牌区、字段池） |
| 样品标签字段默认 | 样品编号、样品名称、型号规格、收样日期、送检单位、检测状态 |
| 样品标签扫码 | 实验室内部流转；扫码展示 = 标签左侧配置的字段信息 |
| 纸张/打印 | 浏览器打印即可；不做标签机协议 |
| 合格打印入口 | 样品管理新增「合格打印」；主表按样品行展示；仅合格样品 |
| 单位名 | 可配；默认取机构名，打印前/模版侧可编辑 |
| Logo | 可开关；默认显示系统 Logo；可自定义上传 |
| 检验人员 | 最多 2（上限参数化）；首次必选；之后记忆 |
| 门禁 | 报告签发及后续 **且** 判定合格；不合格禁止打证 |
| 本期交付 | 先定稿设计文档，再做原型 |

### 2.1 术语：`inspectors`（检验人员）

上一版草案中的 `inspectors` **不是样品主数据字段**，而是合格证打印时选择的**检验人员姓名**（现网弹窗最多 2 人，写入证面「检验人员」行，并记忆上次选择）。  
样品标签字段池**不包含**检验人员；合格证字段池保留，显示名默认可改为「检验人员」。

## 3. 配置形态分析与推荐

> 参考文件《安全工器具合格证样式2.docx》中图1、图2（两种合格证）、图3（第三种合格证样式）、图4（样品标签）。  
> **当前仓库未包含该文件**，下列「布局预设」按「多样式并存 + 结构化编辑」结论给出；图1–图4 的精确槽位/尺寸/对齐在拿到样例后补进 §4.3 / 附录 A。

### 3.1 为什么不用「纯 Word 上传」做主路径

| 点 | 说明 |
|----|------|
| 载体 | 标签/合格证是小尺寸卡片/贴纸，不是 A4 报告 |
| 你已要求的编辑能力 | 纸张布局、品牌区、字段勾选排序改名 —— 更适合结构化编辑器 |
| 多样式 | 图1/图2/图3 是同一业务下的几种**固定骨架**，适合做成「布局预设」，而不是让实施每次从空白 Word 排版 |
| 扫码联动 | 样品标签扫码页字段与证面字段同源配置，结构化模型更容易保证一致 |
| 与单据模版差异 | 委托书等仍走 Word；标签/合格证走独立配置，避免和小尺寸打印拧在一起 |

### 3.2 推荐形态：**布局预设（骨架）+ 结构化版式编辑器（填充）**

```
选择布局预设（图1 / 图2 / 图3 / 图4…）
        ↓
编辑纸张尺寸 / 边距 / 字号档
        ↓
编辑品牌区（单位名、标题、Logo 显隐与图源）
        ↓
从字段池勾选、排序、改显示名
        ↓
绑定本大类下多个样品叶节点
        ↓
预览 → 启用
```

- **布局预设**：固化「图几」的区域划分（如左字段右码、上品牌下双栏、竖版等），不可被字段排序打乱骨架。
- **结构化填充**：在预设允许的槽位内配置品牌与字段；字段超出预设容量时提示裁切或换预设。
- **不采用**「上传任意底图任意拖拽」作为一期能力（复杂度高、和小尺寸打印难控）；若图3 强依赖特殊底纹/边框，允许预设内置背景图资源，仍用结构化填字。

### 3.3 与「单据模版字段分流」的差异

| | 单据模版 | 本设计 |
|--|----------|--------|
| 隔离 | 大类 × 单据类型 | 大类 × 打印物类型（标签 / 合格证） |
| 分流键 | 委托登记字典字段选项 | **样品主数据叶节点**多选绑定 |
| 文件 | Word 版本 | 布局预设 + JSON 版式定义 |

## 4. 信息架构

### 4.1 配置入口

建议放在系统配置侧（与「单据模版」「参数设置」同级或并列），名称：**标签与合格证模版**。

```
标签与合格证模版
  ├─ 顶部：样品大类 Tab / 下拉（电力物资类、安全工器具类…）
  └─ 左侧类型：样品标签 | 合格证
       └─ 右侧：该大类下模版列表
            ├─ 新建模版
            ├─ 每行：名称、布局预设、已绑样品数、启用状态、操作
            └─ 编辑 → 版式编辑器 + 样品绑定
```

规则：

- 切换大类只看到该大类模版，互不影响。
- 同一大类、同一类型下可有多套模版（不同样品组用不同版式）。
- 每个模版**桶内**仍可保留简单版本历史（可选，一期可用单版本 +「另存为」）；若做版本，启用规则为「同模版仅一个启用版」。

### 4.2 样品绑定

- 绑定对象：当前大类样品树中的**样品叶节点**（与样品数据页一致：标准下的样品，如「绝缘操作杆」），**不是**规格型号。
- 一个模版可勾选多个样品。
- **同一大类、同一打印类型下，一个样品只能绑定一个启用模版**（保存时校验冲突，提示已占用模版名）。
- 未绑定任何启用模版的样品：打印时回退该大类该类型的「默认模版」（见 §4.4）；若无默认模版则阻断并提示先配置。

> 待确认：绑定粒度是否仅为样品叶，还是需要细化到「规格型号」？（见 §10 Q-A）

### 4.3 版式编辑器

分三区（均要做）：

#### A. 纸张与布局

| 项 | 说明 |
|----|------|
| 布局预设 | 合格证：`cert_style_1` / `cert_style_2` / `cert_style_3`（对应图1–图3）；样品标签：`label_style_1`（图4） |
| 纸张宽高 | mm；预设带默认值，允许微调 |
| 边距 / 字号档 | 紧凑 / 标准 |

#### B. 品牌区

| 项 | 说明 |
|----|------|
| 单位名称 | 默认 = 系统「委托机构 / 检测机构」名称（见 §10 Q-B）；模版可改默认文案；打印页仍允许本次覆盖 |
| 标题 | 合格证默认「合 格 证」；标签可空或「样品标签」 |
| Logo | 开关；开：默认系统 Logo，可上传自定义；关：不展示 |

#### C. 字段槽位

- 左侧字段池，右侧已选列表（拖拽排序）。
- 每项可改**显示名**（证面/标签上的 label）。
- 二维码为独立槽位（合格证 = 验真短链；样品标签 = 内部流转码，载荷见 §6）。

**合格证字段池（初稿）**

| 字段 ID | 默认显示名 | 数据来源 |
|---------|------------|----------|
| specimenNo | 试样编号 | 试样/样品编号 |
| sampleName | 试样名称 / 样品名称 | 样品名称 |
| specModel | 型号规格 | 规格 \| 型号 |
| inspectDate | 检验日期 | 检测/报告检验日期 |
| reinspectDate | 再检日期 | 主数据再检周期：数值→日期，文本→原文 |
| inspectors | 检验人员 | 打印时选择（≤N） |
| orgName | （品牌区）单位名称 | 品牌配置 |
| qrCode | 二维码 | 短链 |

**样品标签字段池（初稿）**

| 字段 ID | 默认显示名 | 默认勾选 | 数据来源 |
|---------|------------|----------|----------|
| sampleNo | 样品编号 | ✓ | 样品/试样编号 |
| sampleName | 样品名称 | ✓ | 名称 |
| specModel | 型号规格 | ✓ | 规格型号 |
| receiveDate | 收样日期 | ✓ | 收样时间 |
| clientName | 送检单位 | ✓ | 委托单位/送检单位 |
| detectStatus | 检测状态 | ✓ | 当前流程状态 |
| qrCode | 二维码 | ✓ | 内部流转码 |

### 4.4 默认模版

每个「大类 × 类型」可标记**至多一个**「默认模版」：

- 用于未显式绑定样品的回退；
- 默认模版可不绑样品，或绑「剩余未分配」语义（实现上：未命中专用模版 → 默认）。

### 4.5 运行参数（参数设置）

| 参数键 | 名称 | 默认 | 说明 |
|--------|------|------|------|
| `cert.inspector.max` | 合格证检验人员上限 | `2` | 打印弹窗最多可选人数 |
| `cert.shortlink.days` | 合格证短链有效期(天) | `365` | 已有；需真正接入短链逻辑 |
| `cert.shortlink.base` | 短链 Base URL | （环境） | 文档已要求可配 |
| `label.qr.base` | 样品标签扫码落地 Base | （环境） | 内部流转扫码页前缀 |

## 5. 数据模型（草案）

```javascript
// 按大类隔离
LABEL_CERT_CONFIG[catKey] = {
  sample_label: {
    templates: [ Template, ... ],
    defaultTemplateId: 'tpl_xxx' | null
  },
  certificate: {
    templates: [ Template, ... ],
    defaultTemplateId: 'tpl_yyy' | null
  }
}

Template = {
  id, name, enabled, updatedAt,
  layoutPreset: 'cert_style_1' | 'cert_style_2' | 'cert_style_3' | 'label_style_1',
  paper: { wMm, hMm },
  style: { fontScale: 'compact' | 'normal', marginMm },
  brand: {
    orgName,          // 模版默认单位名
    title,
    logoMode: 'system' | 'custom' | 'hidden',
    logoUrl: null | string
  },
  fields: [
    { id: 'sampleName', label: '样品名称', visible: true },
    // order = 数组顺序
  ],
  qr: {
    enabled: true,
    sizePx: 100,
    payloadType: 'sample_flow' | 'cert_shortlink'
  },
  bindSampleIds: ['rod', 'belt976', ...]  // 样品叶节点 id
}
```

### 5.1 运行时解析

```
resolveTemplate(catKey, type, sampleMasterId):
  list = LABEL_CERT_CONFIG[catKey][type].templates.filter(t => t.enabled)
  hit = list.find(t => t.bindSampleIds.includes(sampleMasterId))
  if hit: return hit
  defId = LABEL_CERT_CONFIG[catKey][type].defaultTemplateId
  return list.find(t => t.id === defId) || null
```

打印页：`null` → 提示「该样品未配置模版」。

## 6. 样品标签：扫码与展示

- 标签二维码载荷：指向内部页（或短码）`/label/s/{token}`（原型可用 query）。
- **扫码结果页展示的字段集与顺序 = 该样品命中模版中已勾选的字段**（不含二维码自身），与标签左侧信息一致。
- 用途：实验室内部扫码流转；**不走**合格证验真短链，不作真伪背书。

## 7. 合格打印（样品管理）

### 7.1 菜单位置

`样品管理` 下新增菜单：**合格打印** → `cert-qualified-print.html`（名可调）。

与现「试验管理 → 标签打印」关系（建议，见 §10 Q-C）：

| 页面 | 职责 |
|------|------|
| 标签打印 | 仅保留**样品标签**打印（任意可流转阶段） |
| 合格打印 | **合格证**唯一业务入口 |

### 7.2 列表

- 粒度：**样品一条一行**（业务样品实例，不是委托聚合行）。
- **仅展示判定结论为合格**的样品；不合格不出现、不可打证。
- 另需满足流程：所属委托处于**报告签发及后续**；否则不展示或操作禁用（建议直接过滤，避免无效行）。

**主查询 / 列**

| 列 | 说明 |
|----|------|
| 样品名称 | |
| 样品编号 | |
| 委托编号 | |
| 合同编号 | |
| 委托单位 | |
| 委送样时间 | |
| 客户要求完成时间 | |
| 操作 | 打印合格证（单条）；支持多选批量打印 |

查询条件与上列字段对齐（样品名称/编号、委托编号、合同编号、委托单位、时间范围等）。

### 7.3 打印流程

```
勾选合格样品 →（若首次或需重选）检验人员弹窗（≤ cert.inspector.max）
  → 按样品 resolveTemplate(certificate)
  → 预览（模版驱动渲染）→ window.print()
  → 首次打印签发/复用短链（现有短链规则）
```

- 单位名：预览区带出模版默认（源于机构名），允许**本次打印前编辑**（不写回模版，除非在配置页改）。
- 流程回退导致短链作废：仍按短链文档，与模版无关。

### 7.4 门禁（硬规则）

同时满足才可打印合格证：

1. 委托状态 ∈ 报告签发及后续（现 `canShowCert` 集合）；
2. 该样品**判定合格**；
3. 短链未因回退作废（作废则需按短链规则处理；不合格样品根本不进列表）。

不合格：**禁止打印**（列表不可见 + 接口层拒绝）。

## 附录 B. 与旧硬编码证面的迁移

现 `buildCertHtml` 固定：单位名、标题、六字段、右 QR。迁移策略：

1. 为「安全工器具类」预置一套 `cert_style_*` 模版，字段与现网一致，并绑定演示样品；
2. 打印页改为 `renderByTemplate(tpl, data)`；
3. 旧硬编码删除或仅作无配置时的开发回退（生产路径禁止）。

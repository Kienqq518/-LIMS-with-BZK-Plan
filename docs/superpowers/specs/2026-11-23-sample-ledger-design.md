# 样品台账页面设计（定稿）

对照 App：`Kienqq518/testos-mobile` `main` · `src/components/lims/sample-query.tsx`（菜单名「样品查询」）。

已拍板：名单一行一件样品；详情走独立页。

## 范围

- 样品管理新增只读页「样品台账」。
- 页面：`sample-ledger.html`（名单）、`sample-ledger-detail.html`（详情）。
- 不替代样品收样 / 制备 / 发样 / 还样 / 退样 / 合格打印。
- 委托详情现有「样品台账」弹窗是本单时间线，与本页并存；弹窗提供「在样品台账中打开」。
- 数字孪生 102 房间「样品台账」是库存统计块，不是本页。

## 入口与权限

- 菜单：样品管理 → 样品台账，排在合格打印之后。
- 权限：系统管理员、样品库管理员、检测员、报告审核员可进。全部只读。
- 无权限：菜单不出现；直开 URL 出无权限提示。

## 名单（sample-ledger.html）

粒度：一行 = 一件样品（样品编号）。同一委托多件样品多行。

查询区（对齐现有收样名单）：

- 委托编号、样品编号、样品名称、客户单位、样品大类
- 日期范围：委托日期 / 收样日期 + 开始日期 ~ 结束日期（可自选；空表示不限）
- 当前节点（多选，委托登记 → 任务完成）、流转状态、检测结果、检测时效（未逾期 / 逾期）
- 按钮：查询、重置、导出（导出当前筛选结果）

流转状态走查询区下拉。选项：全部、待接收、待检、在检、待审核、已完成、留样、已处置、退回。

检测结果走查询区下拉。选项：全部、合格、不合格、已过期、/（尚无结论）。

名单固定按样品编号倒序，查询区不提供排序。

Web 不做相机扫码。样品编号框接收扫码枪或粘贴标签号，回车即查。

表列（列配置可记忆；序号、样品编号、操作锁定；样品编号钉在左侧）：

| 列 | 规则 |
|---|---|
| 序号 | 锁定 |
| 样品编号 | 进详情；要求完成日期前未完成报告签发则在编号后标「逾期 n 天」 |
| 委托编号 | 进委托详情 |
| 样品名称 | |
| 流转状态 | 待接收 / 待检 / 在检 / 待审核 / 已完成 / 留样 / 已处置 / 退回 |
| 检测结果 | 合格 / 不合格 / 已过期 / / |
| 当前节点 | 委托任务当前步（委托登记 → 任务完成）；含回退时橙色「含回退」 |
| 委托日期 | |
| 收样日期 | 未收样写 — |
| 要求完成日期 | 只写日期 |
| 样品大类 | 与现网样品大类列一致 |
| 客户单位 | |
| 操作 | 查看 → 详情页；打印标签 → 样品标签打印预览 |

合格结果可点开合格证预览。逾期：在要求完成日期当天仍未完成报告签发。

空结果：无匹配样品时提示核对样品编号，或缩短委托号 / 名称 / 客户关键词。

## 详情（sample-ledger-detail.html）

页首：样品编号（可附逾期标签）、样品名称、流转状态、检测结果；下一行委托编号与当前任务节点。点当前节点展开委托任务 18 步。只读。

详情主体用 Web 端 tab 切换，默认「流转台账」。字段取本原型已有数据，不照搬外部字段表：

1. 样品信息：样品标识（编号、名称、大类、产品标记、型号/分类、规格、检测类别、数量）+ 来源信息（委托编号、委托单位、委托日期、任务类型、要求完成日期、生产厂家、生产厂家地址、制造商、制造商地址）+ 接收信息（收样时间、收样人、收样状态、送样方式、送样人、送样人联系方式、到样情况、下次再检日期、样品图片）
2. 检测信息：试验项进度表（含检测依据）+ 原始记录单（列与委托详情一致：序号、名称、覆盖样品、生成模式、生成时间、状态、操作）
3. 流转台账：当前存放位置 + 实物路径表格（见下节）
4. 结果报告：检测结论 + 合格证证面直接展示（不跳转）+ 报告文档（编号、状态、签发日期）

返回名单保留查询条件、排序、滚动位置。

## 流转台账

样品实物路径，不是整单 18 节点。正向：

委托登记 → 收样 → 制备 → 发样 → 领样 → 检测 → 还样 → **留样 或 退样（二选一）**

- 还样之后只能走留样或退样其中一条，不能两条都走，也不能先后都出现。
- 尚未还样时，留样、退样都不出现。
- 制备未发生则不写该步。
- 未发生的正向步骤灰色，排在已发生步骤后面。
- 同一环节多人各记一条（领样、检测）：办理人、地点、时间、说明。
- 回退：橙色节点，标「回退」，例如退回发样。
- 一件样品多试样时，台账可挂试样行。
- 只读，不能补录或改台账。

## 流转状态

| 状态 | 判定 |
|---|---|
| 待接收 | 尚未收样 |
| 待检 | 已收样、试验尚未开始 |
| 在检 | 试验进行中 |
| 待审核 | 试验完成，处于组内审核到报告审核 |
| 已完成 | 已完成报告签发且未走留样/退样 |
| 留样 | 还样后走留样 |
| 已处置 | 还样后走退样 |
| 退回 | 当前处于回退节点（如退回发样） |

检测结果：合格 / 不合格 / 已过期（超过要求完成日期仍未出结论） / /（尚无结论）。

逾期与检测结果「已过期」分开：逾期看报告签发是否在要求完成日期前完成。

## 跨页

- 样品编号 → 本详情
- 委托编号 → 委托详情；返回回到本样品详情
- 合格状态 → 合格证预览
- 报告编号 → 对应报告记录
- 委托详情「样品台账」弹窗 → 「在样品台账中打开」带该委托编号过滤名单

## 边界

- 不能在台账里收样、发样、领样、还样、退样、改判。
- 回退只作为台账节点展示。
- 无独立退回管理菜单。

## 演示数据

与 App 样品查询同源口径，委托号写成现网 `SC2026/xxxx`：

- 合格留样一件（检测完成、还样、留样；不出现退样）
- 同委托检测中一件（多人领样、检测进行中；未还样，无留样/退样）
- 待收样一件
- 不合格退样一件（还样后走退样，不出现留样）
- 已过期一件
- 含「退回发样」再发样、再领样一件

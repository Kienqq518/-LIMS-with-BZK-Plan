# 样品台账页面设计（定稿）

对照 App：`Kienqq518/testos-mobile` `main` · `src/components/lims/sample-query.tsx`（菜单名「样品查询」）。

已拍板：名单一行一件样品；详情走独立页。

## 范围

- 样品管理新增只读页「样品台账」。
- 页面：`sample-ledger.html`（名单）、`sample-ledger-detail.html`（详情）。
- 不替代样品收样 / 制备 / 发样 / 还样 / 退样 / 合格打印。
- 委托详情现有「样品台账」弹窗是本单时间线，与本页并存；弹窗提供「在样品台账中打开」。
- 数字孪生 102 房间「样品台账」是库存统计块，不是本页。

## 入口与权限

- 菜单：样品管理 → 样品台账，排在合格打印之后。
- 权限：系统管理员、样品库管理员、检测员、报告审核员可进。全部只读。
- 无权限：菜单不出现；直开 URL 出无权限提示。

## 名单（sample-ledger.html）

粒度：一行 = 一件样品（样品编号）。同一委托多件样品多行。

查询区（对齐现有收样名单，字段对齐 App 筛选抽屉）：

- 委托编号、样品编号、样品名称、客户单位、样品大类
- 日期类型：委托日期 / 收样日期；范围：近 1/3/6 个月、今年、去年、前年、自定义
- 当前节点、检测结果、检测时效（未逾期 / 逾期）
- 按钮：查询、重置、导出

快捷标签（与 App 一致，单选）：全部、待收样、检测中、已检测、合格、不合格、过期。

排序（与 App 一致）：委托日期最新/最早、收样日期最新/最早、样品编号升/降、检测时效最紧急/最宽松。默认委托日期最新在前。

Web 不做相机扫码。样品编号框接收扫码枪或粘贴标签号，回车即查。

表列（列配置可记忆；序号、样品编号、操作锁定）：

| 列 | 规则 |
|---|---|
| 序号 | 锁定 |
| 样品编号 | 进详情 |
| 委托编号 | 进委托详情 |
| 样品名称 | |
| 样品大类 | 与现网样品大类列一致 |
| 客户单位 | |
| 委托日期 | |
| 要求完成日期 | 逾期红并写已逾期 N 天；剩 2 天及以内橙并写剩 N 天 |
| 当前节点 | 流转台账当前步；回退时橙色「回退」 |
| 检测进度 | 已完成/总项；含不合格项时写出项数 |
| 状态 | 待收样 / 检测中 / 合格 / 不合格 / 已过期 |
| 存放位置 | 收样台 / 样品库 / 检测室 / 留样室 / 已退回客户 |
| 操作 | 查看 → 详情页 |

合格状态可点开合格证预览（现有合格打印能力）。其他状态点状态或「查看」进详情。

空结果：无匹配样品时提示核对样品编号，或缩短委托号 / 名称 / 客户关键词。

## 详情（sample-ledger-detail.html）

页首：样品编号、样品名称、状态；下一行委托编号（链接到委托详情）与当前任务节点。点当前节点展开委托任务 18 步（委托登记 → … → 任务完成），已过打勾，当前标「当前」，未到灰色。只读。

区块桌面默认展开，顺序：

1. 委托信息：委托编号、委托日期、委托单位、任务类型、要求检测日期（时效着色同名单）
2. 样品信息：样品编号、产品标记 / 型号分类 / 规格（按可判定口径）、检测类别、数量、生产厂家、下次再检日期（无则 —）
3. 流转台账：见下节
4. 检测进度：完成条 + 试验项（名称、检测员、未开始/检测中/已完成、合格/不合格）
5. 检测结果：合格写出具时间；不合格列出不合格项；检测中写已完成项数；待收样写尚未收样；已过期写超过要求检测日期、不能出具结论
6. 原始记录：已完成试验各一份；文件名 = 样品编号 + 样品名称 + 试验项记录单
7. 报告：该样品所属报告及状态；点报告编号进报告编制/审核侧已有报告记录入口

返回名单保留查询条件、标签、排序、滚动位置。

## 流转台账

样品实物路径，不是整单 18 节点。正向：

委托登记 → 收样 → 制备 → 发样 → 领样 → 检测 → 还样 → **留样 或 退样（二选一）**

- 还样之后只能走留样或退样其中一条，不能两条都走，也不能先后都出现。
- 尚未还样时，留样、退样都不出现。
- 制备未发生则不写该步。
- 未发生的正向步骤灰色，排在已发生步骤后面。
- 同一环节多人各记一条（领样、检测）：办理人、地点、时间、说明。
- 回退：橙色节点，标「回退」，例如退回发样。
- 一件样品多试样时，台账可挂试样行。
- 只读，不能补录或改台账。

## 状态

| 状态 | 判定 |
|---|---|
| 待收样 | 尚未收样 |
| 检测中 | 已收样且试验未全部完成 |
| 已检测 | 仅快捷标签：合格或不合格 |
| 合格 | 试验完成且结论合格 |
| 不合格 | 试验完成且存在不合格项 |
| 已过期 | 超过要求完成日期仍未出结论；或下次再检日期已过（详情状态用「已过期」，快捷标签用「过期」） |

## 跨页

- 样品编号 → 本详情
- 委托编号 → 委托详情；返回回到本样品详情
- 合格状态 → 合格证预览
- 报告编号 → 对应报告记录
- 委托详情「样品台账」弹窗 → 「在样品台账中打开」带该委托编号过滤名单

## 边界

- 不能在台账里收样、发样、领样、还样、退样、改判。
- 回退只作为台账节点展示。
- 无独立退回管理菜单。

## 演示数据

与 App 样品查询同源口径，委托号写成现网 `SC2026/xxxx`：

- 合格留样一件（检测完成、还样、留样；不出现退样）
- 同委托检测中一件（多人领样、检测进行中；未还样，无留样/退样）
- 待收样一件
- 不合格退样一件（还样后走退样，不出现留样）
- 已过期一件
- 含「退回发样」再发样、再领样一件

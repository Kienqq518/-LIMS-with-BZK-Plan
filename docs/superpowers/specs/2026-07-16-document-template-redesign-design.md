# 单据模版与模板管理导航整改设计

**日期**: 2026-07-16  
**范围**: 模板管理全页导航重构 + 单据模版卡片化  
**状态**: 已实现（原型）；单据种类与字段分流见 [2026-07-28-doc-template-field-bind-design.md](./2026-07-28-doc-template-field-bind-design.md)

## 背景

单据模版原为表格 + 筛选 + 新增，与「固定单据类型」的业务不符。模板管理入口原先先选业务大类再选模版类型，与任务流不匹配。

## 信息架构

1. **Landing**：四个模版类型卡片（报告 / 记录单 / 单据 / 页眉页脚）
2. **详情页**：`← 返回` 回 Landing；跨类型切换仅通过返回
3. **大类横向 Tab**：报告 / 记录单 / 单据 共用（电力物资类、安全工器具类、环境检测、工程检测）
4. **页眉页脚**：无大类 Tab，全局配置

## 单据模版 UI

- **左列表 + 右详情**（替代原双列卡片）
- 左：单据名称 + 状态摘要（统一模版 / 按字段分流 / 缺默认 / 已关闭）
- 右：系统生成开关、字段分流、选项纵向列表、版本列表与上传
- 右下角保存（仅当前大类）

## 交互规则

| 规则 | 行为 |
|------|------|
| 卡片默认 | 全部开启 |
| 卡片关闭 | 整卡置灰，保留启用单选，内部仍可维护 |
| 保存校验 | 开启且「默认」桶无模版 → 失败，toast + 标红 + 滚动定位 |
| 切换大类/返回 | 有未保存修改 → 弹窗【保存 / 不保存 / 取消】 |

## 数据模型

见 [字段分流绑定设计](./2026-07-28-doc-template-field-bind-design.md)。摘要：

```javascript
DOC_CONFIG[catKey][docType] = {

  buckets: { '__default__': [{ name, time, enabled }], [optionValue]: [...] }
}
```

大类 key：`dlwz` / `aqgqj` / `hjjc` / `gcjc`

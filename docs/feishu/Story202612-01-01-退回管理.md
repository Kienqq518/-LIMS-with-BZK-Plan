# Story202612-01-01 退回管理

1. 委托登记到任务完成，各环节退回要同一套采集和展示，不能每页各写一套原因、各弹一个窗。
2. 同一委托 / 同一份报告可能被退回多次，新退回必须追加，不得覆盖旧原因、旧退回人、旧时间。
3. 主查询页要能看见「从后续节点退回本环节」的任务， 委托编号列表旁打「退回」标签；报告编制页把 AI 自动退回单独放在查询表上方红框里，人工退回走名单标签。
4.没有「报告记录」的环节加「退回详情」列。报告模块已有报告记录，不再单列退回详情。任务完成不能退回归档，归档名单不挂退回标签。
5. 退回必须填原因，且只能退到上一节点（除了委托确认->委托登记，数据审核->试验检测）。
6. 报告编制页面：一个委托下多份报告被ai审核自动退回时，条幅按报告编号分卡片；每份报告右侧「去处理」，点击跳转到对应报告的审核工作台。

## 需求描述

### 背景

检测业务从委托登记到任务完成跨多个节点。退回发生在相邻节点，以及「委托确认 → 委托登记」「数据审核 → 试验检测」两条路径。同一委托、同一报告可被多次退回。各环节若各自采集原因、各自弹窗、各自覆盖最新一条，接收人无法在主查询页识别「从后续节点退回本环节」的任务，也无法追溯历史原因、退回人与时间。

### 目标

- 委托登记到任务完成，退回采集与展示共用一套能力：同一采集弹窗、同一份 `returns[]`、同一套名单标签 / 退回详情 / 报告记录 / 编制页 AI 条幅。
- 每次退回追加一条独立记录。旧原因、旧退回人、旧时间保持可读。
- 接收节点主查询页展示从后续节点退回本环节的任务；委托编号旁打「退回」标签。
- 报告编制页将 AI 自动退回与人工退回分开：AI 自动退回在查询表上方红框，人工退回走名单标签。

### 范围

- **节点**：委托登记 → 委托确认 → 费用审核 → 样品制备 → 样品发样 → 试样分发 → 试验检测 → 组内审核 → 数据审核 → 报告编制 → 报告审核 → 报告签发 → 报告处理 → 收费审批 → 报告发放 → 任务归档 → 任务完成。
- **系统**：轻量 LIMS、物资 LIMS。
- **覆盖**：统一采集弹窗；主查询页「退回」标签；无「报告记录」环节的「退回详情」列；报告模块「报告记录」抽屉；报告编制页 AI 自动退回条幅；试验检测行级 / 整相展示；数据审核整单展示。
- **边界**：无独立「退回管理」菜单页。不可自选任意历史节点。不可一次退回多级。任务完成退回任务归档不适用。任务归档名单不挂退回标签。组内审核不承接入站退回。委托详情只读页、套打字段不展示整段 `returns[]` JSON。

### 流程

1. 当前节点操作人点击「退回」。
2. 打开统一采集弹窗。退回节点只读为「当前节点 → 目标节点」。原因必填。
3. 确认后系统向 `returns[]` 追加一条记录（`code / from / to / by / time / reason / kind`，报告场景含 `reportNo`，试验检测入站含试验项 / 样品 / 试样行 / 相别 / 检测员）。
4. 任务进入目标节点主查询页。
5. 接收节点按本需求展示标签、退回详情、报告记录或编制页 AI 条幅。

**退回方向**：目标节点固定为上一节点。允许路径如下。

| 发起节点 | 目标节点 | 说明 |
|---|---|---|
| 委托确认 | 委托登记 | 允许路径。整单 |
| 费用审核 | 委托确认 | 上一节点。整单 |
| 样品制备 | 费用审核 | 上一节点。整单 |
| 样品发样 | 样品制备 | 上一节点。整单 |
| 试样分发 | 样品发样 | 上一节点。整单；多人退回时每人一条时间轴 |
| 试验检测 | 试样分发 | 上一节点。整单 |
| 组内审核 | 试验检测 | 上一节点。行级；有相别则整相 |
| 数据审核 | 试验检测 | 允许路径，跳过组内审核。行级；有相别则整相 |
| 报告编制 | 数据审核 | 上一节点。整单（该委托下全部报告一并退回） |
| 报告审核 | 报告编制 | 上一节点。按报告编号。AI 自动退回进编制页红框；人工退回走编制名单标签 |
| 报告签发 | 报告审核 | 上一节点。按报告编号 |
| 报告处理 | 报告签发 | 上一节点。按报告编号 |
| 收费审批 | 报告处理 | 上一节点。按报告编号。只退勾选的报告，未勾选的留在收费审批 |
| 报告发放 | 收费审批 | 上一节点。按报告编号。只退勾选的报告，未勾选的留在报告发放 |
| 任务归档 | 报告发放 | 上一节点。整单 |
| 任务完成 | — | 无退回入口。退回任务归档不适用 |

### 规则

**采集**

- 各环节操作列 / 弹窗底栏「退回」打开同一采集窗。标题：退回。原因：必填多行。空原因不可确认、不落库。
- 退回节点只读，不可改。目标仅上一节点。允许路径：委托确认 → 委托登记；数据审核 → 试验检测（跳过组内审核）。
- 报告编制：该委托下任一报告已进入报告审核或之后，「退回」置灰。全部报告仍在编制时，允许整单退回数据审核。
- 任务完成无「退回」操作。
- AI 严重项策略自动退回编制，无需人工确认。

**记录**

- 全链路只维护一份 `returns[]`。每次确认退回追加一条。查询按时间倒序（新在前）。禁止把原因写回任务主字段做覆盖。
- 必有字段：`code`（委托编号）、`from`（发起节点）、`to`（目标节点）、`by`、`time`、`reason`、`kind`（人工 / AI / 系统）。
- 报告环节字段：`reportNo`（如 SC2026/0238-03）。
- 试验环节字段：`item / sample / tester / testers[] / rows[{specimen, phase}]`。`phase` 非空表示整相退回。试样分发 `testers[]` 每人一个时间轴节点。
- 条幅、名单标签、退回详情弹窗、报告记录时间轴均读这一份数据。

**粒度**

- 默认整单退上一节点。
- 组内审核 → 试验检测、数据审核 → 试验检测：按单条试样数据退回。一组样品同屏时，未退回的行不打标。该试验项存在相别时，同一样品编号下某一相只要有一条退回，该相全部试样退回。
- 组内审核不承接入站退回。数据审核的目标节点为试验检测，组内审核主查询页与编辑页不出现被退回数据。
- 报告编制 → 数据审核：该委托下全部报告一并退回。数据审核编辑页按整单展示，试验项名称后不打退回标签。
- 收费审批 → 报告处理、报告发放 → 收费审批：按报告退回。只退勾选的报告，每份报告一条记录并带 `reportNo`。未勾选的报告留在当前节点，同一委托可以同时出现在两个节点的名单上。
- 报告编制及之后可挂 `reportNo`。

**主查询页**

- 从后续节点退回本环节的任务出现在该环节主查询页。
- 委托编号旁打「退回」标签，编号与标签同一行、不换行。悬停：从「{from}」退回 · 原因。
- 任务归档、任务完成名单不挂退回标签。
- 组内审核主查询页不挂退回标签（本环节无入站退回）。
- 除报告编制页外，各环节主查询表上方不放退回红框。退回信息走名单标签、「退回详情」或「报告记录」。

**退回详情列与报告记录**

- 无「报告记录」的环节（委托登记、委托确认、费用审核、样品制备 / 发样、试样分发、试验检测、组内审核、数据审核等）：名单设「退回详情」列。有记录显示「查看」，无记录显示「—」。
- 报告模块（报告编制、报告审核、报告签发、报告处理、收费审批、报告发放）已有「报告记录」，名单不单列「退回详情」。退回历史在「报告记录」抽屉中查看。报告审核名单「报告记录」列之后直接是操作列。
- 签发 / 处理 / 收费 / 发放名单委托编号旁打「退回」标签。

**报告编制页 AI 条幅**

- 位置：查询区下方、主表上方。数据：`to = 报告编制` 且 `kind = AI`。人工退回不进此框，走委托行「退回」标签。
- 头文案：「有 N 条委托存在 AI 自动退回」（N 为委托数）。按委托分组，组头为委托编号。
- 同一委托下多份报告被 AI 审核自动退回时，条幅按报告编号分卡片。每张卡片同一行：报告编号、「AI 自动退回」胶囊、从「{from}」退回 · 时间；右侧「去处理」，点击跳转到对应报告的审核工作台。下一行：原因。
- 条幅高度随内容增高；内容未到最大高度时收至刚好包住内容；超过最大高度后内部滚动。

**编辑页条幅**

- 试验检测、数据审核编辑页顶部退回条幅高度固定 152px，内部上下滚动。
- 组内审核编辑页不挂退回条幅。
- 数据审核被报告编制整单退回时，仅顶部条幅展示整单退回记录；页头不写「将鼠标悬浮在图标上，可查看退回原因」。

**试验检测详情**

- 接收组内审核与数据审核的行级退回。被退回试验项名称后打退回标签；被退回试样行浅红底、编号旁打标。有相别列时，整相退回该相全部试样打标。
- 感叹号悬停气泡：上行是退回原因全文；下方「来源 / 退回人 / 时间 / 类型」分行对齐。人与时间不括在原因后面。
- 表头展示检测员、检测时间。
- 组内审核编辑页无试样退回标、无试验项退回标签。

**退回详情弹窗**

- 点「查看」打开「退回详情 · {委托编号}」。标题含「退回记录共 N 次」。时间轴新到旧，最新一条红点。
- 芯片：第 N 次、来源 {from}、种类（人工 / AI / 系统）。界面不含「退回至 {to}」，不含「新到旧 · 追加不覆盖」。
- 每条独立展示原因、退回人、时间。
- `testers[]` 有几个人退回就展开几个时间轴节点，每人各自原因与时间。

**报告记录时间轴**

- 编制 / 审核 / 签发及之后的「报告记录」抽屉，退回节点为拒绝态（红点），原因单独成块。
- 报告审核 / 签发工作台当前任务旁可挂退回条，数据为该委托、该节点的 `returns[]`。
- 报告处理、收费审批、报告发放的操作弹窗：被退回的报告在操作列提供「查看退回原因」。点击后弹出该报告自己的退回记录（第 N 次、来源、原因、退回人、时间），多份报告各看各的。没有报告编号的整单退回，操作列同样是「查看退回原因」，弹出整单记录。

**原始记录表**

组内审核、数据审核编辑页「原始记录表」列与委托详情 / 原始记录页一致：序号、原始记录名称、覆盖样品、生成模式、生成时间、状态、操作；按本单试验项各出一份文件。

**演示数据**

SC2026/0209 委托确认 → 委托登记；SC2026/0238-02 报告审核人工退回编制；SC2026/0238-03 AI 自动退回编制；SC2026/0238-04 签发退回审核；SC2026/0312 处理退回签发；SC2026/0190 收费审批把 SC2026-0190-01、SC2026-0190-03 退回报告处理（原因各不相同），SC2026-0190-02 仍在收费审批；SC2026/0285 报告发放把 SC2026-0285-01、SC2026-0285-03 退回收费审批，SC2026-0285-02 仍在报告发放；SC2026/0052 组内审核退回试验检测（操作杆交流耐压 02、07 单条，横担红相整相）；SC2026/0062 数据审核退回试验检测（硬梯交流耐压红相整相）；SC2026/0060 数据审核退回试验检测（抗弯第 4 条）；SC2026/0055 报告编制整单退回数据审核。任务完成 → 归档不适用。

### 异常

- 原因为空：不可确认，焦点回到原因输入框，不落库。
- 目标节点非上一节点，且不是「委托确认 → 委托登记」「数据审核 → 试验检测」：操作不适用。
- 任务完成退回任务归档：不适用。
- 报告编制「退回」：该委托下已有报告进入审核或签发后置灰；悬停说明卡在哪个节点。
- 组内审核无入站退回数据：名单无退回标签，编辑页无条幅、无试样退回标。

### 验收

- [ ] 任意节点点退回：原因空不能确认；填因后任务到目标节点，且旧退回记录仍在。
- [ ] 非编制页主查询表上方无退回红框；从后续节点退回本环节的任务出现在该环节主查询页，委托编号旁有「退回」标签；无「报告记录」的环节「退回详情」为查看。
- [ ] 退回详情弹窗有第 N 次 / 来源 / 人工（或 AI），没有「退回至 …」，没有「新到旧 · 追加不覆盖」。
- [ ] 报告编制条幅只含 AI 自动退回（如 SC2026/0238-03），不含人工退回 0238-02；同一委托多份报告按报告编号分卡片；每份报告右侧有「去处理」，点击进入对应报告的审核工作台；来源节点与时间和编号、AI 标签同一行；内容少时条幅收至内容高度。
- [ ] 编制列表：委托下已有报告进入审核 / 签发后，「退回」置灰。
- [ ] 报告审核名单无「退回详情」列；「报告记录」抽屉能看到签发退回 / 审核退回。
- [ ] 任务归档名单委托编号旁无退回标签；任务完成不能退回归档。
- [ ] 试验检测：被退回试验项名称后有退回标签，并显示检测员与检测时间；名单上方无退回红框。单条退回只标对应试样行；有相别时整相打标。
- [ ] 试验检测 / 数据审核编辑页顶部退回条幅高度固定 152px，内容超出后内部滚动。组内审核编辑页无退回条幅。
- [ ] 试验检测 SC2026/0062 硬梯交流耐压红相整相打标（来源数据审核）；SC2026/0060 抗弯无相别只打第 4 条。组内审核详情与名单均无退回标。数据审核退回直接到试验检测。
- [ ] 感叹号悬停气泡上行是退回原因，下方分行展示来源 / 退回人 / 时间 / 类型。
- [ ] 组内审核名单无退回标签；数据审核退回标签与委托编号同一行不换行。
- [ ] 数据审核 SC2026/0055 编辑页顶部有整单退回记录，试验项名称后无退回标签，页头无「悬停看退回原因」；原始记录表含覆盖样品 / 生成模式 / 状态 / 操作，与委托详情列一致。
- [ ] 同一委托连续退回两次，详情时间轴为 2 条，原因互不覆盖。
- [ ] 收费审批退回报告处理、报告发放退回收费审批按勾选的报告，不整单。未勾选的报告留在原节点。SC2026/0190 的 01、03 在报告处理且弹窗里各写各的原因，02 仍在收费审批；SC2026/0285 的 01、03 在收费审批，02 仍在报告发放。操作列「查看退回原因」点开后只展示该报告的原因。

## 本次对齐要点（相对原 Story 正文）

### 一、报告模版

1. **文案**：正文模板 → **报告模版**；公共头尾模板 → **公共模版**。
2. **二级 Tab**：报告模版 | 公共模版。
3. **公共模版**
   - 内容样式：模板头 / 模板尾 / **正文**
   - **无关联绑定**（无绑定列、无绑定筛选）；由报告模版侧直接引用
   - 操作：编辑 | 版本 | 配置 | 预览 | 删除
   - **编辑 vs 版本**：编辑仅改内容样式与模版名称（启用文件只读）；文件上传/复制/启用/改名走「版本」；名称与启用文件名解耦；已被引用不可改内容样式
   - **批量下载**：列表复选框 + 工具栏「批量下载」
4. **报告变体**
   - 模版正文文件：上传 / 复制 / **引用**公共正文（活引用 `refPublicId`）
   - 编辑弹窗内重新上传/复制 = 追加新版本并启用；也可到「版本」管理
   - 「当前启用版本」**不展示「启用中」**；引用公共正文展示「引用」
5. **默认变体**：可选（0 或 1 个）
6. **批量下载**：报告模版列表 + **公共模版**列表均有复选框与工具栏「批量下载」；未选置灰，选中后高亮

### 二、记录单模版

1. **二级 Tab**：记录单模版 | **公共模版**
2. **公共模版**：组合记录单模版 / 试验项模版；无关联绑定；编辑/版本职责同报告公共；**支持批量下载**
3. **记录单模版 Tab**：保留上下分区（组合 + 试验项）
4. **编辑**：上传 / 复制 / 引用公共模版（活引用）；本地也可在此重新上传/复制追加启用
5. **版本**：本地多版本管理；引用行打开公共侧版本
6. **批量下载**：试验项表 + **公共模版**表复选框 + 工具栏「批量下载」；交互同报告（未选不高亮）

## 1. 需求背景

记录单模版配置需支持按 **样品层 / 型号层** 绑定组合模版（一份 Word 含绑定范围内全部试验项），并与现有 **试验项单模版**（型号 × 试验项）并存。导出时由「业务流程配置 › 记录单设置」中的生成模式决定取组合模版、运行时继承或试验项动态拼接，操作员在导出抽屉不再选择策略。

**现状问题**

- 原记录单模版仅支持单试验项绑定；合并类导出只能依赖各试验项模版拼接，无法维护「全套记录单」Word。
- 组合模版与试验项模版若混在同一表格，筛选与操作边界不清。
- 左侧树选中层级与右侧展示范围不一致，不利于分类/样品层批量查看。

**本次整改目标**

- 支持 **样品层、型号层** 上传组合记录单模版；**分类层不上传**，仅汇总展示与说明。
- 保留试验项单模版能力；页面 **上下分区**：组合记录单模版表格 + 试验项模版表格。
- 右侧展示遵循：**左侧每选中一层级，展示该层级及以下全部相关数据**（组合区与试验项区分别计算）。
- 继承仅在 **导出运行时** 解析（型号 → 样品）；UI **不展示**继承态，文件列仅 `xxx.docx` / `未上传`。
- 「是否已配置」仅统计本节点实际上传；依赖上级继承 **不算** 已配置。
- 生成模式 UI 统一使用「**单个样品**…」，不使用「试样」。

**配置优先级**

```
记录单设置（生成模式） > 记录单模版（组合 + 单试验项） > 导出抽屉（仅预览与执行）
```

**生成模式（4 种 UI 文案）**

| 模式 | UI 文案 |
|------|---------|
| 合并 · 按型号 | 单种样品所有试验生成一份文件 |
| 切分 · 按型号 | 单种样品单种试验生成一份文件 |
| 合并 · 按样品实例 | 单个样品所有试验生成一份文件 |
| 切分 · 按样品实例 | 单个样品单种试验生成一份文件 |

## 3. 用户故事

| 角色 | 用户故事 | 价值 |
|------|---------|------|
| 模版管理员 | 作为模版管理员，我希望在 **样品层** 上传一份包含该样品下全部试验项的组合记录单，以便合并类导出时一次生成完整记录单 | 减少按试验项维护多份 Word 的成本 |
| 模版管理员 | 作为模版管理员，我希望在 **型号层** 单独上传组合模版，以便同一样品下不同型号使用不同版式 | 满足型号差异 |
| 模版管理员 | 作为模版管理员，我希望选中 **分类/样品/型号** 时，右侧组合表展示 **本层级及以下** 全部组合模版行，以便批量查看与维护 | 与左侧树认知一致 |
| 模版管理员 | 作为模版管理员，我希望 **试验项单模版** 独立在下方表格维护，以便切分类模式与无组合时的拼接回退 | 职责清晰 |
| 模版管理员 | 作为模版管理员，我希望选中 **试验项** 时不再看到组合模版区域，以便聚焦当前试验项 | 减少干扰 |
| 模版管理员 | 作为模版管理员，我希望在版本弹窗内 **复制其他项** 复制组合/试验项模版，列表未上传行仅显示「版本」 | 统一版本管理入口 |
| 检测员 | 作为检测员，我在导出抽屉仅预览与执行，不能改生成模式，以便遵循管理员配置 | 策略一致 |
| 检测员 | 作为检测员，合并类导出时系统自动取型号/样品组合模版或拼接试验项模版，以便无需手工选模版来源 | 导出自动化 |

## 5. 验收标准

### 5.1 组合模版区域

- [ ] 组合区为表格，列为：绑定层级、绑定对象、覆盖范围、模板文件、操作；**无「适用模式」列**。
- [ ] 绑定对象列可完整展示较长名称（约 300px）；操作列仅包裹四个按钮宽度，**右侧无明显空白**。
- [ ] 选中 **分类层**：组合表展示下属全部样品层 + 型号层行；无子级数据时展示说明行。
- [ ] 选中 **样品层**：组合表 1 行样品层 + 其下全部型号层行；型号行顺序与左侧树 **C→U→M→H** 一致。
- [ ] 选中 **型号层**：组合表仅 1 行。
- [ ] 选中 **试验项**：组合模版标题与表格 **均不显示**。

### 5.2 试验项模版区域

- [ ] 下方表格 **仅** 试验项单模版，不含组合行。
- [ ] 数据范围为选中节点本层级及以下；样品层选中时按型号分组。
- [ ] 模板文件为「未上传」的行，操作列 **仅「版本」**，**无「复制」**。
- [ ] 已上传行：配置、版本、预览、清除可用。
- [ ] 工具栏有「批量下载」：未勾选时置灰不高亮；勾选任意已上传行后高亮可点；未上传行复选框禁用。

### 5.3 版本与复制

- [ ] 组合模版「版本 › 复制其他项」弹窗表头与组合表一致（含单选、序号），**无「试验项」列**。
- [ ] 试验项「版本 › 复制其他项」弹窗保持试验项维度筛选与列。

### 5.4 筛选与文案

- [ ] 筛选栏无「样品分类」「模版类型」；查询/重置与筛选项同一行。
- [ ] 「是否配置模板=否」可命中仅依赖继承、本节点未上传的组合/试验项行。
- [ ] 区块副标题、底部说明条使用四种生成模式 **完整 UI 文案**（不出现「模式 1/2/3/4」或「试样」）。

### 5.5 导出联动（原型）

- [ ] 型号 UI「未上传」、样品已上传：合并类导出仍成功（运行时取样品组合模版）。
- [ ] 合并类无组合且试验项模版不齐：提示 `缺少「{试验项名}」的模版`。
- [ ] 切分类模式：忽略组合模版，仅校验对应试验项单模版。

### 5.6 关键文案（可直接对照 UI）

**组合区副标题**

> 用于「单种样品所有试验生成一份文件」「单个样品所有试验生成一份文件」。分类层不支持上传，请在样品层或型号层配置；导出时自动解析型号 → 样品。

**试验项区副标题**

> 用于「单种样品单种试验生成一份文件」「单个样品单种试验生成一份文件」；「单种样品所有试验生成一份文件」「单个样品所有试验生成一份文件」无本型号/上级样品组合模版时，按试验项单模版动态拼接。

## 6. 依赖与约束

### 6.1 依赖

| 依赖项 | 说明 |
|--------|------|
| 业务流程配置 › 记录单设置 | 提供 4 种生成模式；导出切分规则以该配置为准 |
| 模板管理 › 报告模版树 | 记录单左侧树层级与正文模板树一致 |
| PageOffice | 组合/试验项模版「配置」入口 |
| 试验检测 › 记录单导出抽屉 | 消费 `resolveCombinedTemplate()` 及试验项模版解析结果 |
| 前置 Story | 记录单设置整改（生成模式、绑定规则）需先就绪 |

### 6.2 约束

| 约束 | 说明 |
|------|------|
| 分类层不可上传组合模版 | 分类节点仅汇总展示 + 说明，无上传/配置按钮 |
| 不展示继承态 | UI 文件列仅 `xxx.docx` / `未上传`；不在界面标注「继承自上级」 |
| 是否已配置 | 仅本节点实际上传且启用中 = 已配置 |
| 不提供 | 行级「复制」、恢复继承、卡片级独立复制（复制统一走版本弹窗） |
| 试验项增删 | 不自动作废已上传组合模版；生成时按当前试验项列表渲染 |
| 本次范围 | 原型 HTML/JS；**不含**后端 API、权限、真实文件上传 |
| 关联实现文件 | `template-config.html`、`js/record-export.js`、`test-detect-edit.html`、`system-params.html` |

### 6.3 边界情况

| 场景 | 预期 |
|------|------|
| 型号未上传、样品已上传 | UI 型号「未上传」；导出合并类用样品组合模版 |
| 型号清除组合模版 | UI「未上传」；导出回退样品或拼接 |
| 无样品层的型号（如绝缘手套） | 仅型号层可上传组合；无组合则直接拼接 |
| 带承口/直管等多样品 | 各样品层、型号层独立维护；分类层汇总展示 |

## 1. 背景与目标

在保留「试验项单模版」（一试验项一模版）能力的基础上，新增 **样品层 / 型号层组合模版**（一份 Word 含绑定范围内全部试验项占位），与单模版并存。导出时按「业务流程配置 › 记录单设置」中的生成模式自动选择组合模版、继承解析或试验项动态拼接。

**不在本次范围**：分类层上传组合模版、后端 API、复制弹窗以外的全局交互改造。

---

## 2. 术语

| 术语 | 含义 |
|------|------|
| **样品层** | 树中直接包含 ≥1 个型号子节点的节点，如 `DS实壁类塑料电缆导管_直管` |
| **型号层** | 型号节点，如 `PVC-C` |
| **组合模版** | 绑定样品层或型号层，一份 Word 含该绑定范围内全部试验项 |
| **试验项单模版** | 现有按「型号 × 试验项」绑定的模版 |
| **动态拼接** | 无可用组合模版时，按各试验项启用单模版拼接为一个 Word |

### 生成模式（UI 全文案）

| 模式 | UI 文案 |
|------|---------|
| 合并 · 按型号 | **单种样品所有试验生成一份文件** |
| 切分 · 按型号 | **单种样品单种试验生成一份文件** |
| 合并 · 按样品实例 | **单个样品所有试验生成一份文件** |
| 切分 · 按样品实例 | **单个样品单种试验生成一份文件** |

> UI 使用「单个**样品**」，不使用「试样」。

## 3. 配置优先级

```
记录单设置（生成模式） > 记录单模版（组合 + 单试验项） > 导出抽屉（仅预览与执行）
```

## 4. 绑定与数据规则

| 规则 | 说明 |
|------|------|
| 可上传层级 | **样品层、型号层**；**分类层不可上传** |
| 版本规则 | 多版本、单启用；新上传/复制默认启用最新版 |
| 是否已配置 | 仅本节点实际上传且启用中 = 已配置；依赖上级继承 **不算** 已配置 |
| 继承 UI | **不展示**继承态；模版文件列仅 `xxx.docx` / `未上传` |
| 继承链（仅导出） | 型号层组合模版 → 上级样品层组合模版 → 无则试验项拼接；**不含分类层** |

## 6. 组合记录单模版表格

### 6.1 列定义

| 绑定层级 | 绑定对象 | 覆盖范围 | 模板文件 | 操作 |
|---------|---------|---------|---------|------|

- **不含**「适用模式」列。
- **绑定对象**列较宽（约 300px），长名称省略号展示。
- **操作**列按内容收紧，仅容纳按钮，右侧不留大段空白。

### 6.2 按左侧选中节点展示（本层级及以下）

| 选中节点 | 组合模版区域 |
|---------|-------------|
| **分类层** | 展示范围内 **全部样品层 + 型号层** 组合模版行；无数据时展示说明行（分类层不支持上传） |
| **样品层** | **本样品层 1 行** + **其下全部型号层** 各行（含未上传） |
| **型号层** | **仅本型号 1 行** |
| **试验项** | **整区隐藏**（不展示组合模版标题与表格） |

**排序**：同层级多行顺序与 **左侧树节点顺序** 一致（如 PVC-C → PVC-U → PVC-M → PVC-H）。

### 6.3 操作按钮

| 状态 | 操作 |
|------|------|
| 已上传 | 配置 · 版本 · 预览 · 清除 |
| 未上传 | **版本**（用于上传；卡片/行上无独立「复制」） |

- **配置**：PageOffice 编辑本节点启用中组合模版；未上传时 disabled。
- **版本**：上传、复制其他项、改名、删除、启用切换。
- **清除**：仅清除本节点模版文件；导出时自动回退上级或拼接。

**不提供**：行级「复制」按钮、恢复继承、上传独立模版（复制走版本弹窗）。

### 6.4 版本弹窗 · 复制其他项

复制弹窗表头与 **组合模版表格一致**（前加单选、序号列）：

| （单选） | 序号 | 绑定层级 | 绑定对象 | 覆盖范围 | 模板文件 | 操作 |

- **不含**「试验项」列、**不含**「适用模式」列。
- 组合模版复制时隐藏「试验项」筛选项。

## 10. 区块说明文案

**组合记录单模版 · 副标题**

> 用于「单种样品所有试验生成一份文件」「单个样品所有试验生成一份文件」。分类层不支持上传，请在样品层或型号层配置；导出时自动解析型号 → 样品。

**试验项模版 · 副标题**

> 用于「单种样品单种试验生成一份文件」「单个样品单种试验生成一份文件」；「单种样品所有试验生成一份文件」「单个样品所有试验生成一份文件」无本型号/上级样品组合模版时，按试验项单模版动态拼接。

**底部说明条**

> 记录单模版支持 **样品层 / 型号层组合模版**（一份 Word 含全部试验项），以及各 **试验项单模版**。分类层不支持上传组合模版。  
> **「单种样品所有试验生成一份文件」「单个样品所有试验生成一份文件」**：优先本型号组合模版；若无则上级样品组合模版；若仍无则按试验项单模版动态拼接；拼接时缺任一试验项模版则报错。  
> **「单种样品单种试验生成一份文件」「单个样品单种试验生成一份文件」**：始终使用各试验项单模版，忽略组合模版。  
> 导出切分规则由「业务流程配置 › 记录单设置」决定。同一模版可存多个版本，同时仅启用一个。

## 11. 导出模版解析（摘要）

### 合并类两种模式

1. `resolveCombinedTemplate(型号)`：本型号组合 → 上级样品组合 → null  
2. 有组合 → 1 份文件（按模式切分样品实例）  
3. 无组合 → 试验项单模版动态拼接；缺任一项 → `缺少「{试验项名}」的模版`

### 切分类两种模式

- 始终使用试验项单模版，**忽略**组合模版。

## 12. 边界情况

| 场景 | 处理 |
|------|------|
| 型号未上传、样品已上传 | UI 型号行「未上传」；导出合并类自动用样品组合模版 |
| 型号清除 | UI「未上传」；导出回退样品层或拼接 |
| 无样品层的型号 | 仅型号层可上传；无组合则直接拼接 |
| 分类节点 | 组合区汇总子级行；不可上传 |
| 试验项选中 | 隐藏组合区；试验项表仅对应行 |
| 试验项增删 | 不自动作废已上传组合模版 |

---

## 13. 验收要点（原型）

1. 组合区为 **表格**，列无「适用模式」；试验项选中时组合区 **隐藏**。
2. 样品层选中：组合表展示样品 1 行 + 下属型号多行，顺序 **CUMH**。
3. 分类层选中：组合表汇总下属全部样品层、型号层行。
4. 试验项表与组合表 **分离**；未上传行操作列 **仅「版本」**。
5. 组合版本弹窗「复制其他项」表头与组合表一致，无「试验项」列。
6. 筛选无「样品分类」「模版类型」；说明条与模式名称使用完整 UI 文案。
7. 型号「未上传」、样品「已上传」：筛选「未配置」命中型号行；导出合并类仍可用样品模版。

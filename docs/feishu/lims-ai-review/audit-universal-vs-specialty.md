# 通用 vs 品类专属 审计（原则对齐）

判定原则（与产品约定一致）：

1. **通用**：凡报告（不论品类）都必然涉及的概念/字段；不进绑定表，始终执行。
2. **品类专属**：概念并非所有品类都有，**或** 正确执行必须依赖品类方法包/参数表 → 只进绑定表，启用由实验室确认。

### 2. 在原始诉求上扩展的定稿方案

#### 2.1 配置隔离与模版角色

- 按**样品大类**隔离配置（与报告/记录单大类 Tab 一致）。
- 每大类 × 类型（合格证 / 样品标签）固定一份**默认模版**：可编辑版式，不可删除 / 停用 / 绑定样品，兜底全部未覆盖样品。
- **个性化模版**：绑定 ≥1 个样品**叶节点**后覆盖默认；可启停、可删除；停用或删除后回退默认。
- 冲突：同大类同类型下，一样品仅可属于一个**启用中**的个性化模版。
- 解析：`启用个性化命中绑定` → 否则 → `默认模版`。

#### 2.2 可视化配置能力（对应 44）— 仅自由设计

**不做**布局预设模式 / 双模式。唯一路径：

1. **定纸张**：宽高 mm（空白新建时可选尺寸快捷，或自定义）  
2. **布局**：从分类元件库投放元素，在画布上拖拽定位、缩放、对齐、设层级  
3. **内容**：同画布切换「内容」面板，逐个调整元素文案、字段绑定、样式等  

编辑器结构：左元件库 / 中毫米画布 / 右「布局 | 内容」双面板（随时切换，无强制向导）。

**元件分类**

| 分类 | 元素 |
|------|------|
| 品牌标识 | 单位名称、标题、Logo（各最多 1 个） |
| 业务字段 | 字段行（同一 `fieldId` 最多 1 个） |
| 码与章 | 二维码（最多 1 个）；检测章、文本水印（可多枚，可**置于底层/顶层**） |
| 装饰辅助 | 静态文本、分割线、悬挂孔 |

**新建模版**

- **空白创建**：名称 + 纸张尺寸快捷（65×30 / 65×45 / 50×25 / 90×50 / 60×40 等）或自定义 → 空画布  
- **复制已有模版**：仅当前大类 × 当前类型；深拷贝纸张与元素；**清空样品绑定**；**结果一律为个性化模版**（不可另存为第二个默认）  
- **不提供**系统布局预设 / 一键骨架  

**其它**

- 实时预览（样例数据灌值）/ 打印同源渲染（`paper + elements[]`）  
- 备注：材质、安装、赋码方式 — 仅说明不渲染  
- 单位名称元素默认检测机构名（B1）；Logo：系统 / 上传 / 隐藏  

合格证字段池：试样名称、规格型号、试样编号、检查员、本次/下次检测日期、检测有效期、送检单位等（**不含合格证编号**）。  
样品标签字段池：样品编号、样品名称、型号规格、收样日期、送检单位、检测状态 + 流转二维码。

#### 2.3 样品标签字段（对应 49 / 48）

字段池提供上述 6 项 + 右侧/任意位置可放内部流转二维码（非验真短链）。扫码展示页字段 = 模版上已配置的业务字段行（建议按坐标排序）。

#### 2.4 合格证字段与再检周期（对应 42 / 46 / 48）

- 证面通过字段行元素绑定业务字段；再检周期文本型原文展示，数值型换算为日期。  
- 检验人员：打印时选择，上限参数化（默认 2）；首次必选，之后记忆。

#### 2.5 打印入口与门禁

- **试验管理 → 标签打印**：保留样品标签 + 合格证双入口；渲染改为模版 `elements` 驱动。  
- **样品管理 → 合格打印**（新增）：样品一行；仅判定合格且报告签发及后续。  
- 合格证门禁：报告签发及后续 **且** 判定合格；不合格禁止打证。  
- 打印页：左预览 + 右样品列表勾选。

#### 2.6 二维码分工（对应 79）

| 类型 | QR 用途 | 编码 |
|------|---------|------|
| 合格证 | 外部/现场验真 | 短链 → 302 → 验真 H5 |
| 样品标签 | 实验室内部流转 | 内部落地页（展示标签已配字段） |

短链细节见同 Story「样品标签合格证打印时二维码的短链方案」。

### 3. 验收要点（摘要）

1. 大类 × 类型具备默认模版；可空白新建或复制为个性化并绑定样品；复制结果不能成为第二个默认；冲突与启停规则正确。  
2. 编辑器为自由画布：无布局预设选择；可投放分类元素、调布局与内容；字段/品牌/QR 唯一性正确；水印/章可置底/置顶。  
3. 样品标签字段池含建议 6 字段，不含检测日/下次检测日作为池内主推项。  
4. 合格证可配字段含规格型号、送检单位；再检周期文本/数值表现符合 42。  
5. 打印页左预览右列表；合格证 QR 为短链形态。  
6. 不合格或未到签发后续不可打合格证。

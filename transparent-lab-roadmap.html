PART 01

理念与标准
为什么要做透明实验室

透明检测把检测过程从"交付一纸结论"升级为"交付可核验的全过程"，用一份企业标准，把"透明度"变成可评级、可承诺、可招投标的核心竞争力。

数蚕智能 · 透明实验室方案02
Concept · 透明检测理念

把检测"黑箱"变"玻璃房"

核心理念：从「结果交付」升级为「过程交付」，实现「检测即所见」。"一报一码"是实验室诚信与能力的数字身份证——扫码即可远程审计本次检测的全要素。

对客户

  • 扫码远程审计，检测过程可视
  • 降低采信风险，结论有据可溯
  • 不必到场，随时回看关键节点

对实验室

  • 招投标差异化，不再单拼价格
  • 透明度=能力等级，可对外承诺
  • 面向国央企 / 电网等高端市场

对行业

  • 从"人防 / 制度防"转向"技防 / 物联防"
  • 物联数据自动上报，天然防篡改
  • 重塑检测公信力评价体系
一句话

透明检测卖的不再只是"结论"，而是"看得见、可核验、改不了"的过程信任。这正是我们区别于传统 LIMS 的护城河。

数蚕智能 · 透明实验室方案03
Standard · Q/YM 006—2026

四级透明度模型与"双核心"评级

依据《检测报告透明度等级评价规范》，以「① 二维码信息公开完整度 + ② 数据流转自动化程度」为双核心，由高到低分四级；报告等级 = 实验室对应的透明运行与数据防篡改能力等级。

一级全要素

八维度 100% + 全程连续视频 + 实时监控；全链路自动闭环、人员不可篡改。

二级可视化

八维度完整 + 关键节点视频；高度自动化，仅少量人工复核。

三级可追溯

八维度核心信息 + 2–5 张关键照片，无视频；数据修改全程留痕。

四级可公示

最低合规信息，无任何影像；人工录入为主，简单存储。

关键规则 · 等级前置选定

检测前按客户需求选定本次报告等级，选定后必须严格执行，严禁降级出具；报告一码终身绑定、不可复用、不可篡改。

产品策略

一 / 二级为核心竞争力（国央企 / 电网 / 招投标）；三级面向普通市场化业务；四级仅内部整改，不外推。

Eight Dimensions · 八大维度

扫码可见的八个维度

在传统"人机料法环 + 试验流程 + 过程影像"基础上，标准新增了核心维度——「数据流转」：人员干预越少、自动流转越高、篡改概率越低，等级越高。

机

料
样品来源、编号、全流程自动流转、耗材合格证明 / 批次
法
执行标准全文、作业指导书、算法固化自动计算
环
全过程温湿度曲线、环境布局、安全环保、自动上传
试验流程
委托—收样—制样—检测—复核—报告全节点时间 / 责任人留痕
过程影像
关键节点照片 / 关键环节视频 / 全程连续视频 / 实时监控
数据流转 ★
采集→传输→存储→计算→复核→生成全自动，人员不可篡改、全程留痕
诚实降级原则

缺失维度一律显式标注「暂未采集」或「该等级不公开」，绝不用占位数据充数——透明的前提是真实。

数蚕智能 · 透明实验室方案06
Foundation · 技术底座

四方协同的物联采集底座

透明度的物理基础，是「组态物联终端 + 数采系统 + 上位机 + LIMS」的协同：物联数据自动上报、减少人工干预、天然防篡改。LIMS 不直连硬件，而是经数采系统中转。

组态物联终端

公司另一款产品，温湿度 / 视觉 / 水浸等物联节点，负责现场环境与影像的原始采集。

数采系统

绑定设备与试验项，中转采集任务与数据回传，是 LIMS 与物联终端之间的桥梁。

上位机

拉取试验任务、做物模型绑定（点选具体节点）、控制试验开始 / 结束。

LIMS（本系统）

下发采集任务、消费数采回传，归一化为维度快照，出具透明报告。

数蚕智能 · 透明实验室方案07
Architecture · 架构骨架

五个骨架构件：一次搭好、后续不动

聚合器与公开引擎都面向"维度契约"而非具体模块。新增或补强某维度时，只实现该维度适配器，骨架与公开页零改动——这就是"后续慢慢加模块"的技术保障。

1报告透明度等级配置

检测前为本次报告选定 level（1–4），受"能力门禁"约束，当前仅放行三 / 四级。

2维度采集适配器接口

每维度统一契约 collect(ctx)→DimensionSnapshot；缺失能力返回 not_collected。

3八维度信息聚合器

调用各适配器，产出本次报告的全量维度快照 + 采集状态。

4分级公开引擎

以"等级 × 维度公开矩阵"过滤快照，只吐出该等级应公开的字段。

5报告码 + 公开页 + 存证

签发生成唯一码、冻结快照、写防篡改存证；扫码走公网只读公开页。

设计原则

  • 骨架稳定 · 一次搭好不随维度增减而变
  • 维度可插拔 · 每维度一个采集适配器
  • 等级按能力解锁 · 缺失降级为占位
数蚕智能 · 透明实验室方案08
Data Flow · 溯源链路

从"选定等级"到"扫码核验"的全链路

报告级溯源二维码复用现网"合格证短链"基建（QR→/l/{code}→302→公开 H5），仅新增报告码命名空间与公开页，最小改动、快速落地。

链路六步

  • ① 检测前：为本次报告选定透明度等级（受能力门禁约束）
  • ② 采集：各模块经适配器暴露维度数据（按试验项下发采集任务）
  • ③ 聚合：八维度聚合器归集为报告快照
  • ④ 签发：生成唯一报告码、冻结快照、写存证（哈希 / 时间戳）
  • ⑤ 印刷：报告首页显著位置印刷溯源二维码
  • ⑥ 核验：委托方 / 监管扫码，分级公开引擎按等级展示八维度

与"合格证短链"的边界

维度合格证短链报告溯源码
绑定对象单个样品整份报告
载体合格证 / 标签报告首页
扫码内容合格与否、再检期八维度分级公开
状态回退即作废永久可查、按业务动作变更

两条溯源线平行、不混用；报告码建议用 R 段前缀区分。

  • 环：温湿度自动采集（数采回传）已打通

  • 过程影像（视频/监控）：二 / 一级，硬件将就绪

Risk & Governance · 风险与保障

四条底线，确保"透明"不失真

透明度是对外的能力承诺，必须与实际能力严格一致，否则名不副实反而损公信力。

能力与承诺一致

等级即能力承诺。能力门禁必须与等级严格绑定，禁止降级出具；建议以全局参数 lab.transparency.authorizedLevel 统一"实验室授权等级"，单报告等级 ≤ min(能力门禁, 授权等级)。

公网暴露面安全

报告全要素公开涉及数据安全：公开页只读、仅吐分级字段，与内网主数据隔离（参考短链方案 2 边缘只读）。

存储期限合规

影像 / 日志按标准分级留存（一级视频 ≥ 3 年、数据流转日志永久等），在参数与归档策略中落地。

诚实降级

缺失维度一律显式"暂未采集"，不得用占位数据充数，避免造假风险。

报告码作废联动

报告码永久可查：三态 valid / revoked / superseded；作废召回后扫码仍可打开并醒目标注，换版则旧码指向新版——契合监管溯源诉求，区别于合格证短链的"回退即作废"。
